Chapter 1 — The Machine Learning Landscape

Machine Learning kya hai, kab istemal karna chahiye, aur kaunse types hote hain — ye chapter poori book ki neev hai. Spam filter ke example se lekar overfitting tak, yahan har concept ki pehchan hogi.

01.1 What Is Machine Learning?

Machine Learning computer science ka wo field hai jo computers ko bina explicitly program kiye seekhne ki ability deta hai. Matlab: rules likhne ke bajaye, computer data se patterns seekhta hai aur unse predictions ya decisions karta hai.

Classic example spam filter hai. Traditional tareeka: programmer haath se rules likhe — 'agar subject me ye word hai to spam'. ML tareeka: filter ko spam aur non-spam ke examples dikhao, wo khud seekh le ki kaunsa pattern spam hai.

Farak saaf hai: traditional program me rules pehle se likhe hote hain; ML system me rules data se niklte hain. Isi liye ML wahan jeet-ta hai jahan rules likhna mushkil ya impossible hai.

01.2 Why Use Machine Learning?

ML tab istemal karo jab: problem rules se solve karna bahut complex ho; rules badalte rehte hon (spam adapt karta rehta hai, isliye fixed rules fail hote hain); data bahut bada ya complex ho haath se analyse karne ke liye; ya system ko naye data se adapt karna ho.

Ek aur badi wajah: ML insaanon ko seekhne me madad karta hai. Model train karke use analyse karo, to data ke baare me aisi baatein pata chalti hain jo seedha dekhne se nahi chalti. Ye Figure 1-2 ka idea hai — ML sirf prediction nahi, insight bhi deta hai.

01.3 Examples of Applications

ML aaj har jagah hai. Kuch bade examples:

  • Image classification — photo me kya hai, pehchanna (jaise kisi photo me billi hai ya kutta).
  • Speech recognition — boli ko text me badalna.
  • Natural-language processing aur translation — ek language se doosri me.
  • Self-driving cars — camera aur sensor data se driving decisions.
  • Recommendation systems — tumhe kya pasand aayega, andaza lagana.
  • Fraud detection — galat transactions pakadna.
  • Medical diagnosis — scans aur reports se bimari ka andaza.
  • Stock-market prediction — market ke patterns se andaza (ye mushkil aur risky hai — ML magic nahi hai).

Table 1-1 me in applications ko task type ke hisaab se list kiya gaya hai — har application ke peeche ek ML task (classification, regression, clustering) chhupa hota hai. Application dekh kar task pehchanna seekho — yahi ML thinking hai.

01.4 Types of Machine Learning Systems — Training Supervision

Sabse pehla classification hai training supervision ke hisaab se — matlab training data me labels hain ya nahi:

  • Supervised learning — labelled training data. Kaam: classification (spam ya nahi) aur regression (keemat kitni hogi).
  • Unsupervised learning — unlabelled data. Kaam: clustering (similar cheezein ek group me), dimensionality reduction, anomaly detection (alag-thalag cheez pakadna).
  • Semisupervised learning — thoda labelled + bahut saara unlabelled data. Example: photo app me kuch photos label ki hain, baaki nahi — system baaki ko bhi seekh leta hai.
  • Self-supervised learning — labels data se hi banaye jate hain. Example: agla word predict karna — text hi label ban jata hai.
  • Reinforcement learning — environment se reward signal milta hai. Example: board game khelna — jeetne par reward, haarne par penalty.

Table 1-2 in types ko ek jagah compare karti hai. Interview me sabse zyada poochha jaane wala sawaal yahi hai: 'supervised aur unsupervised me farak kya hai?' — jawaab ek line me: labels hain ya nahi.

Self-supervised learning aaj ke bade language models ki neev hai — text se hi labels banaye jate hain, isliye itna bada data istemal ho pata hai.

01.5 Batch and Online Learning

Doosra classification hai kab train karte ho — ek baar ya lagatar:

  • Batch learning — poora dataset ek saath train karo. Model ban gaya, phir naya data aane par dobara train karna padta hai. Offline kaam karta hai.
  • Online learning — naya data aate hi thoda-thoda train karo, lagatar. Example: stock prices — har naya price aate hi model update hota hai.

Table 1-3 batch vs online ko compare karti hai. Online learning me ek khaas cheez hai: out-of-core algorithms — jo data ko chhote chunks me padhte hain, kyunki poora data memory me nahi aata. Agar data RAM se bada hai, to out-of-core hi raasta hai.

Online learning ka risk: kharab data aate hi model kharab ho sakta hai — isliye production me data ko monitor karna zaroori hai (Chapter 2 me detail me).

01.6 Instance-Based versus Model-Based Learning

Teesra classification hai kaise generalise karte ho:

  • Instance-based learning — training examples ko yaad rakho, aur naye example ki prediction similarity se karo. Example: k-nearest neighbours — naye point ke sabse kareeb ke k neighbours dekho, unka majority vote lo.
  • Model-based learning — data se ek model banao (jaise ek line ya equation), aur prediction us model se karo. Training ke baad data ki zaroorat nahi — model hi kaafi hai.

Table 1-4 dono ko compare karti hai. Model-based algorithms kya dhoondhte hain? Wo parameter values dhoondhte hain jo ek cost function ko minimise karte hain — aur prediction ke liye wo trained model istemal karte hain. Ye idea poori book me baar-baar aayega: har algorithm ke peeche ek cost function aur ek optimisation strategy hoti hai.

01.7 Main Challenges of Machine Learning

ML mushkil kyun hai? Chhah badi challenges:

  • Insufficient quantity of training data — data hi ML ka fuel hai. Kam data = kamzor model. Deep learning ko to bahut zyada data chahiye.
  • Nonrepresentative training data — sampling bias. Agar training data real duniya ko represent nahi karta, to model real duniya me fail hoga.
  • Poor-quality data — outliers, missing values, noise. Kachra data andar, kachra prediction bahar.
  • Irrelevant features — galat features model ko confuse karte hain. Feature engineering matter karta hai.
  • Overfitting the training data — model training data ko rat leta hai, naye data par fail hota hai. Curse of dimensionality isse badhata hai; regularisation madad karta hai.
  • Underfitting the training data — model bahut simple hai, pattern hi nahi pakad pata.

Overfitting aur underfitting ke beech ka balance hi ML ki asli kala hai — Chapter 4 me is par poori detail hai, learning curves ke saath.

Sabse aam beginner galti: model ko blame karna, jab asal problem data hai. Pehle data check karo, phir model.

01.8 Testing and Validating

Model achha hai ya nahi — kaise jaano? Data ko train aur test set me baanto. Train set par train karo, test set par check karo — test set wo data hai jo model ne kabhi dekha hi nahi.

Cross-validation ek behtar tareeka hai: data ko kai hisson me baanto, har baar ek hissa test ke liye, baaki train ke liye — aur average lo. Isse generalisation ka andaza zyada reliable hota hai.

Data snooping se bacho — test set ko baar-baar dekh kar usi ke hisaab se model badalna. Aisa karoge to test set bhi training set ban jayega, aur asli performance ka pata nahi chalega. Test set ko sirf end me, ek baar, chhoo.

Model train kaise hota hai, asal me? Normal equation se lekar gradient descent, polynomial regression, learning curves, regularisation, aur logistic regression — ye chapter ML ki engine ko khol kar dikhata hai.

04.1 Linear Regression

Sabse simple model: linear regression — data par ek seedhi line fit karo. Do tareeke hain line nikaalne ke: Normal Equation aur Gradient Descent.

Normal Equation: θ = (XᵀX)⁻¹Xᵀy — ek hi step me solution. Example: data banaya gaya y = 4 + 3x + noise (100 points); Normal Equation se θ = [4.215, 2.770] mila — matlab x=0 par prediction 4.215, x=2 par 9.755.

Computational complexity: Normal Equation O(n²·⁴–n³) hai (n×n matrix invert karni padti hai); SVD/pinv O(n²). Bade features par Normal Equation slow ho jata hai — tab gradient descent aata hai.

Gradient Descent

Batch Gradient Descent: poora data ek saath, learning rate η=0.1, 1,000 epochs — Normal Equation wala hi θ milta hai. Learning rate bahut chhota ho to slow; bahut bada ho to diverge kar jata hai. Convex MSE ka ek hi global minimum hota hai — isliye GD yahan safe hai.

Stochastic Gradient Descent (SGD): ek example at a time, learning schedule t0/(t+t1) with t0=5, t1=50, 50 epochs — θ=[4.211, 2.749]. SGDRegressor se [4.213, 2.773]. Mini-batch GD beech ka rasta hai — GPU ko efficiently istemal karta hai.

Learning curves batati hain ki model underfit kar raha hai ya overfit. Do curves plot karo: training error aur validation error, training set size ke against.

Chapter 5 — Support Vector Machines

SVM ka idea simple hai: classes ke beech sabse chaudi 'street' dhoondho. Is chapter me soft margin, kernel trick, RBF, SVR, aur dual problem — sab kuch, numbers ke saath.

05.1 Linear SVM Classification

Large-margin classification: SVM classes ke beech sabse chaudi 'street' (margin) dhoondhta hai. Street ke kinare par jo instances hote hain, unhe kehte hain support vectors — sirf wahi decision boundary tay karte hain.

Scaling matters: SVM feature scales ke prati sensitive hai — features ko scale kiye bina SVM mat chalao.

Hard margin matlab koi violation allowed nahi; soft margin matlab violations allowed hain, aur C control karta hai: chhota C = chaudi street, zyada violations; bada C = patli street, kam violations. Example: iris data par C=1 vs C=100.

05.2 Nonlinear SVM Classification

Data linearly separable na ho to kya karein? Features transform karo — polynomial features jodo. Moons dataset (100 points, noise 0.15) par degree 3, C=10 se kaam ho jata hai.

Kernel trick: transformed features ko explicitly compute kiye bina hi unka dot product nikaal lo. Polynomial kernel: degree 3, coef0=1, C=5; degree 10 overfit kar deta hai.

Gaussian RBF kernel: similarity landmarks se naapi jati hai. Example: x=−1 ke liye landmarks se similarity 0.74 aur 0.30. γ (gamma) width control karta hai — bada γ = patla, irregular boundary; chhota γ = smooth boundary. Example: SVC with RBF, gamma=5, C=0.001.

05.4 Under the Hood

Ab engine ke andar dekhte hain. Decision function: wᵀx+b — iska sign class batata hai, magnitude confidence batata hai. Hinge loss: max(0, 1−t·(wᵀx+b)) — sahi aur confident prediction par zero loss.

Dual problem: Lagrange multipliers α_i ke function ko maximise karo. Dual me hi kernel trick aata hai: φ(a)ᵀφ(b) = (aᵀb)² polynomial kernel ke liye — transform kiye bina dot product mil gaya.

Common kernels: linear; polynomial (γ·aᵀb+r)^d; RBF exp(−γ||a−b||²); sigmoid tanh(γ·aᵀb+r). Mercer's theorem batata hai kaunsa function valid kernel hai. RBF kernel infinite-dimensional feature space se correspond karta hai — isliye itna powerful hai.

Ek khaas baat: predictions sirf support vectors istemal karti hain — baaki training data prediction ke waqt kaam nahi aata. Online SVMs bhi hain, jo naye data se lagatar seekhte hain.

SVM ko samajhne ka shortcut: decision boundary sirf support vectors par depend karta hai — baaki points hata bhi do to boundary nahi badlegi.

06.4 The CART Training Algorithm

CART (Classification and Regression Trees) ek greedy algorithm hai: har node par wo split chuno jo weighted impurity sabse zyada kam kare. Greedy matlab har step par best decision — global optimum ki guarantee nahi.

Asal me optimal tree dhoondhna NP-complete hai — complexity O(exp(m)). Isliye greedy hi practical raasta hai. Training complexity hai O(n·m·log₂ m).

Dono similar results dete hain. Gini thoda faster hai aur sabse frequent class ko isolate karne ki taraf jhukta hai. Entropy thoda zyada balanced trees banata hai. Default Gini hi theek hai — farak chhota hai.

07.5 Boosting

Boosting matlab weak models ko sequence me train karo — har naya model pichhle ki galtiyan theek kare. Do bade tareeke:

AdaBoost

AdaBoost: galat classify hue instances ka weight badhao. Weight update: α = η·log((1−r)/r) jahan r weighted error rate hai; galat instances ka weight ×exp(α) ho jata hai. SAMME (discrete) vs SAMME.R (real, probabilities istemal karta hai). Example: 30 stumps, learning_rate=0.5.

Gradient Boosting

Gradient boosting: har naya tree pichhle ensemble ke residual errors par fit hota hai. Example: y=3x²+noise 0.05, teen depth-2 trees — X_new=[−0.4, 0, 0.5] ke liye predictions [0.495, 0.040, 0.750]. Learning rate (shrinkage) har tree ka contribution control karta hai. Early stopping n_iter_no_change=10 se 92 trees mile, validation_fraction=10%. HistGradientBoosting: max_bins=255, complexity O(b·m) vs O(n·m·log m); 10,000+ instances par early stopping; categorical features aur missing values handle karta hai. California housing par OrdinalEncoder ke saath istemal hua. XGBoost, CatBoost, LightGBM aur TensorFlow Random Forests faster alternatives ke roop me mention hain.

Chapter 8 — Dimensionality Reduction

100 dimensions me data itna sparse ho jata hai ki usme density dhoondhna impossible hai. Is chapter me curse of dimensionality, PCA, kernel PCA, LLE, aur t-SNE — kam dimensions me zyada samajh.

08.1 The Curse of Dimensionality

Curse of dimensionality matlab: dimensions badhne par data space itna bada ho jata hai ki data sparse ho jata hai. Numbers se samjho:

  • 10,000-dimensional hypercube me >99.999999% points border ke 0.001 ke andar hote hain — 2D me sirf 0.4%. Matlab high dimensions me sab kuch 'kinare' par hai.
  • Do random points ke beech average distance: 2D me 0.52, 3D me 0.66, aur 1,000,000 dimensions me 408.25.
  • 100 dimensions me density 0.1 paane ke liye universe ke atoms se zyada samples chahiye honge.

Isi liye high-dimensional data par distance-based algorithms (jaise k-NN) fail hote hain — sab kuch sab se door ho jata hai. Solution: dimensionality kam karo.

08.2 The Main Approaches for Dimensionality Reduction

Do bade approaches hain:

  • Projection: data ko ek lower-dimensional subspace par project karo. PCA isi ka sabse mashhoor tareeka hai — maximum variance wali directions dhoondho.
  • Manifold learning: data ek nonlinear manifold par rehta hai (jaise Swiss roll — ek rolled sheet). Manifold ko 'unroll' karo, dimensions kam karo.

Projection tab kaam karta hai jab data roughly flat hai; manifold learning tab jab data curved hai. Figure 8-2 dono ko compare karta hai, Figure 8-3 Swiss roll dikhata hai.

08.3 PCA

PCA (Principal Component Analysis) SVD se kaam karta hai: X = U·Σ·Vᵀ. Principal components wo directions hain jinme variance sabse zyada hai.

Explained Variance Ratio

Example me pehle do components ki explained variance ratio 0.758 / 0.152 hai — matlab pehla component 75.8% variance samjhata hai. MNIST par 95% variance bachane ke liye 154 components chahiye (784 me se) — elbow ~100 components par hai.

Choosing the Right Number of Dimensions

Elbow method: explained variance curve me jahan bend aaye, wahi number chuno. Ya target set karo — jaise 95% variance. RandomForest pipeline with 23 components aur 465 trees 1,000 samples par best tha; SGD ko ~70 components chahiye the.

PCA for Compression

154/784 matlab <20% original size — 5× compression, 95% variance ke saath. Reconstruction error wo MSE hai jo original aur reconstructed data ke beech hai. Figure 8-6 me compression aur reconstruction dikhte hain.

Randomized PCA aur Incremental PCA

Randomized PCA: O(m·d²)+O(d³) — jab max(m, n) > 500 aur n_components < 80% of min(m, n) ho to automatically istemal hota hai. Incremental PCA: 100 batches me kaam karta hai, memmap se badi files handle karta hai.

Kernel PCA, LLE, aur Others

Kernel PCA: kernel se nonlinear projection — rbf kernel, gamma=0.04. Random projection theorem: m=5,000, n=20,000, ε=0.1 ke liye d=7,300; sparse random projection 25 MB vs 1.2 GB memory istemal karta hai. LLE (Locally Linear Embedding): k=10 neighbours, Swiss roll 1,000 points noise 0.2 par. MDS, Isomap, t-SNE, LDA — Figure 8-11 in sabko compare karta hai.

09.2 Gaussian Mixtures

Gaussian Mixture Models (GMM) har cluster ko ek Gaussian distribution mante hain — soft assignments ke saath. Example me weights mile [0.39, 0.40, 0.21] (true 0.4, 0.4, 0.2) — bahut kareeb!

Chapter 11 — Training Deep Neural Networks

Deep network train karna mushkil kyun hai? Gradients vanish karte hain, explode karte hain, optimiser atak jata hai, overfitting hota hai. Is chapter me har problem ka solution — initialisation se lekar 1cycle tak.

11.1 Vanishing/Exploding Gradients Problems

Gehre network me gradients ya to vanish (zero ke kareeb) ya explode (bahut bade) ho jate hain — dono se training ruk jati hai. Chaar solutions:

  • Glorot aur He initialisation: Glorot σ²=1/fan_avg, He σ²=2/fan_in, SELU-init σ²=1/fan_in. He ReLU ke liye, Glorot tanh/sigmoid ke liye. (Table 11-1)
  • Nonsaturating activation functions: sigmoid saturate hoti hai; ReLU mar sakta hai (dead neurons); Leaky ReLU α=0.2/0.01, PReLU/RReLU; ELU α=1, smooth; SELU (1.05·x, α≈1.67) self-normalising hai; GELU z·Φ(z), minimum −0.17 at −0.75, approximation z·σ(1.702z); Swish z·σ(βz); Mish z·tanh(softplus(z)).
  • Batch Normalization: har layer ke inputs ko normalise karo — μ, σ², x̂, γ⊗x̂+β, ε=1e-5. ImageNet top-5 error 4.9% validation / 4.8% test with 14× fewer steps. BN parameters 3,136+1,200+400, total 271,346, trainable 268,978, non-trainable 2,368. Momentum 0.9/0.99/0.999. Fuse karne par W′=γW/σ.
  • Gradient clipping: gradients ko limit karo — clipvalue/clipnorm. Example: [0.9, 100] clip karne par [0.9, 1.0] vs [0.009, 0.99996] — clipvalue aur clipnorm ka farak samjho.

11.2 Reusing Pretrained Layers

Training scratch se karna mehenga hai — reuse karo:

  • Transfer learning: model A (8 classes) >90%; model B (sirf 200 images) transfer se 91.85% se 93.85% ho gaya — error −25%. Warning: test data se pretrained model chunna 'cheating' hai — selection bhi training data se karo.

  • Pretraining on an auxiliary task: related task par train karo (jaise face recognition, masked-word prediction), phir asal task par lagao. Auxiliary task se model ko structure samajh aata hai.

Transfer learning ka rule: pehle sirf top layers train karo (frozen base), phir dheere-dheere neeche ki layers unfreeze karo, kam learning rate se.

Transfer learning hi wajah hai ki chhote dataset par bhi deep learning kaam karta hai — bada model pehle se bahut kuch seekh kar aata hai.

11.3 Faster Optimizers

Gradient descent ke behtar versions:

  • Momentum: β=0.9 — gradient ka moving average; terminal velocity learning rate ki 10× ho jati hai. Ravines me tez, oscillations me stable.
  • Nesterov Accelerated Gradient (NAG): pehle momentum se aage badho, phir gradient naapo — θ+βm. Momentum se behtar.
  • AdaGrad: s+=g⊗g — har parameter ka apna learning rate; lekin jaldi ruk jata hai (learning rate bahut chhota ho jata hai).
  • RMSProp: ρ=0.9 — AdaGrad ka fix, recent gradients ko zyada weight.
  • Adam aur Nadam: β1=0.9, β2=0.999, ε=1e-7, bias correction ke saath. AdaMax (ℓ∞), Nadam, AdamW (decoupled weight decay) bhi hain. (Table 11-2)

Learning rate scheduling: exponential η0·0.1^(t/s); piecewise constant; performance scheduling (ReduceLROnPlateau, factor=0.5, patience=5); power scheduling η0/(1+t/s)^c; 1cycle — CIFAR-10 par 91.9% in 100 epochs vs 90.3% in 800 epochs. 1cycle se 8× kam epochs me behtar result!

11.4 Avoiding Overfitting Through Regularization

Deep networks overfit karte hain — teen bade solutions:

  • L1 aur L2 regularisation: Adam ke saath L2 mat lagao — AdamW istemal karo (decoupled weight decay), warna regularisation sahi kaam nahi karta.
  • Dropout: training me random neurons band karo — p=10–50% (RNNs ke liye 20–30%, CNNs ke liye 40–50%). 2^N possible networks bante hain; 1–2% accuracy boost milta hai. Test time par keep probability se divide karo.
  • Max-norm regularisation: weights ki norm limit karo — ||w||₂≤r.

MC dropout: test time par bhi dropout on rakho, 100 samples lo — uncertainty milti hai. Fashion MNIST pehli image: 84.4% → 72.3% (sandal 6.7%, sneaker 20.9%, std 0.183), accuracy 87.0% → 87.2%. Matlab model ko pata hai ki wo kitna unsure hai — ye production me bahut kaam ki baat hai.

14.2 Convolutional Layers

Convolution matlab ek chhota filter (kernel) image par slide karo aur har jagah dot product lo. Example: Conv2D with 32 filters of 7×7 on a batch of 2 images 70×120×3 gives [2, 64, 114, 32]; 'same' padding se output 70×120×32 milta hai. Output size formulas: 'valid' (iw−fw+sw)/sw (floor), 'same' ceil(iw/sw). 14.3 Pooling Layers

Pooling feature maps ko chhota karta hai. Max pooling 2×2 stride 2 size ko aadha kar deta hai. Pooling se invariance milti hai — object thoda shift ho jaye to bhi pehchan me aaye.

14.4 CNN Architectures

CNN ki history — har architecture ek breakthrough:

  • LeNet-5 (1998): input 32×32, C1 6@28×28 (5×5, tanh), S2 6@14×14, C3 16@10×10, S4 16@5×5, C5 120@1×1, F6 84 (tanh), output 10 (RBF). (Table 14-1)
  • AlexNet (2012): top-5 error 17% vs 26.2% runner-up ka — deep learning ki jeet ka moment. 227×227 input, C1 96@55×55 (11×11, stride 4), F9/F10 4,096 units with 50% dropout, LRN (r=5, α=0.0001, β=0.75, k=2).
  • GoogLeNet (2014): top-5 <7%, inception modules with 1×1 bottlenecks, 9 modules, far fewer parameters.
  • VGGNet: 2–3 convolutions + pooling, repeated — simple aur deep.
  • ResNet (2015): top-5 <3.6%, 152 layers, residual f(x)=h(x)−x. ResNet-34 me 3×64, 4×128, 6×256, 3×512 residual units.
  • Xception (2016): depthwise separable convolutions — kam parameters, behtar accuracy.
  • SENet (2017): squeeze-and-excitation block — global average pooling → Dense (ReLU) → Dense (sigmoid) recalibration.

Aur bhi: ResNeXt, DenseNet, MobileNet, CSPNet, EfficientNet (compound scaling α=1.2, β=1.1, γ=1.1, α·β²·γ²≈2). ILSVRC top-5 error chhah saal me 26% se <2.3% ho gaya — ye progress CNN ki wajah se hai.

14.5 Implementing a ResNet-34 CNN Using Keras

ResNet-34 Keras me ~40 lines me ban jata hai. Core hai ResidualUnit class — jab strides>1 ho to ek 1×1 convolution se shortcut ko match karo.

ResidualUnit ka pattern: do convolutions, batch norm, aur shortcut add. Ye pattern 3×64, 4×128, 6×256, 3×512 units me repeat hota hai — poora ResNet-34 ban jata hai.

python
class ResidualUnit(keras.layers.Layer):
    def __init__(self, filters, strides=1, activation="relu", **kwargs):
        super().__init__(**kwargs)
        self.activation = keras.activations.get(activation)
        self.main_layers = [
            keras.layers.Conv2D(filters, 3, strides=strides,
                                padding="same", use_bias=False),
            keras.layers.BatchNormalization(),
            keras.layers.Activation(activation),
            keras.layers.Conv2D(filters, 3, strides=1,
                                padding="same", use_bias=False),
            keras.layers.BatchNormalization(),
        ]
        self.skip_layers = []
        if strides > 1:
            self.skip_layers = [
                keras.layers.Conv2D(filters, 1, strides=strides,
                                    padding="same", use_bias=False),
                keras.layers.BatchNormalization(),
            ]

Chapter 18 — Reinforcement Learning

Agent ko reward se seekhana — game khelna, robot chalana, decisions lena. Policy gradients se DQN tak, aur AlphaGo ki kahani — RL ki poori duniya.

18.1 Learning to Optimize Rewards

RL me agent environment me actions leta hai aur rewards pata hai. Maksad: total reward maximise karo. 2013 me ek mashhoor lab ne Atari games par RL dikhaya; 2016 me AlphaGo ne world champion ko haraya; 2017 me ek aur champion ko bhi. 2014 me Google ne us lab ko >$500M me khareeda.

RL supervised learning se alag hai: yahan labels nahi hain — sirf reward signal hai. Agent ko khud explore karke seekhna padta hai ki kaunsa action achha hai.

18.2 Policy Search

Policy matlab state se action ka mapping — deterministic ya stochastic. Genetic algorithms se policy dhoondh sakte ho: 100 policies, 20 survivors, har ek ke 4 offspring — evolution se behtar policies banti hain.

Policy search ka idea simple hai: policy ko parameterise karo, phir un parameters ko optimise karo taaki expected reward badhe. Policy gradients iska gradient-based version hai — aage detail me.

18.3 Introduction to OpenAI Gym

OpenAI Gym RL ke liye standard toolkit hai. CartPole-v1: reset with seed 42 se observation milti hai [0.0274, −0.0061, 0.0359, 0.0197]; render se 400×600×3 image milti hai; action space Discrete(2) — left ya right; har step par reward 1.0.

18.4 Neural Network Policies

Policy ko neural network se represent karo: Dense(5, ReLU) + Dense(1, sigmoid) — output left/right ki probability deta hai. Network policy genetic algorithm ya policy gradients se train hoti hai.

Neural policy ki taakat: wo complex states se bhi seekh sakti hai — jaise pixels se seedha action. Yehi Deep RL hai.

18.5 Evaluating Actions: The Credit Assignment Problem

Credit assignment problem: episode ke end me reward mila — to kis action ko credit dein? Pehle wale ko ya aakhri wale ko? Discount factor γ iska jawaab hai.

Rewards [10, 0, −50] ke liye γ=0.8 se return −22 hai. γ=0.99 ki half-life 69 steps hai, γ=0.95 ki ~13 steps. Matlab γ=0.99 wala agent 69 steps aage tak sochta hai; γ=0.95 wala sirf ~13 steps.

Discounted rewards [−22, −40, −50] ko normalise karo to [−0.284, −0.866, −1.189] / [1.267, 1.073] milte hain — normalisation se training stable hoti hai.

18.6 Policy Gradients

REINFORCE (1992): policy gradient ka classic algorithm. Training: 150 iterations × 10 episodes × 200 steps, γ=0.95, Nadam lr=0.01, binary_crossentropy loss. Har episode ke baad gradients se policy update karo — achhe actions ki probability badhao, bure ki ghatao.

18.7 Markov Decision Processes

MDP RL ki mathematical neev hai: states, actions, transition probabilities, rewards. Bellman equations value function ko define karte hain — aaj ka value = aaj ka reward + discounted future value.

Example Q-values: [[18.919, 17.027, 13.622], [0, −inf, −4.880], [−inf, 50.134, −inf]]; optimal policy hai [0, 0, 1]; γ=0.95 ke saath state 1 action 2 chunta hai. −inf matlab wo action us state me allowed nahi hai.

18.8 Temporal Difference Learning and Q-Learning

TD learning: δ = r + γ·max Q(s′, a′) − Q(s, a) — prediction aur actual ka farak. Q-learning: α0=0.05, decay 0.005, γ=0.90, 10,000 iterations. Q-iteration <20 iterations me converge karta hai; Q-learning slow hai kyunki wo samples se seekhta hai.

ε-greedy exploration: ε 1 se 0.05 tak ghatao — shuru me explore karo, baad me exploit karo. Exploration function f = Q + κ/(1+N) — kam try kiye gaye actions ko bonus do.

18.9 Q-Learning with Deep Q-Networks

DQN: Q-function ko neural network se represent karo — Dense 32 ELU ×2, replay buffer (deque) of 2,000, batch 32, γ=0.95, Nadam lr=1e-2, MSE loss, 600 episodes, ε 1 se 0.01 over 500 episodes, training 50 episodes ke baad shuru. Catastrophic forgetting se bacho — replay buffer purane experiences ko yaad rakhta hai. ELU vs ReLU — ELU yahan behtar hai.

Fixed Target Q-Values

Target network ko har 50 episodes me clone karo — warna target hilta rehta hai aur training unstable hoti hai. ε 1 se 0.1 over 1,000,000 steps; Atari ke liye 50,000,000 steps chahiye the.

Double DQN

Double DQN: online network action chune, target network uski value naape — overestimation kam hota hai.

Prioritized Experience Replay

Prioritised experience replay: ζ=0.6, β=0.4→1, priority p=|δ| — badi galti wale experiences zyada baar replay karo.

Dueling DQN

Dueling DQN: Q = V + A — value aur advantage alag-alag seekho, mean advantage subtract karo (A* = 0). Rainbow (2017) chhah techniques ko combine karta hai.

Appendix B — Autodiff

Neural networks gradients se seekhte hain — lekin gradients compute kaise hote hain? Manual differentiation se lekar reverse-mode autodiff tak — ye appendix backprop ki neev hai.

B.1 Manual Differentiation

Example: f = x²y + y + 2. Partial derivatives: ∂f/∂x = 2xy aur ∂f/∂y = x² + 1. Point (3, 4) par gradients hain 24 aur 10. Haath se karna chhote functions ke liye theek hai — bade networks ke liye impossible.

B.2 Finite Differences

Finite differences: gradient ka andaza lagao — f(x+ε) − f(x) ko ε se divide karo. ε=1e-5 se gradients mile 24.00004 aur 10.00000000033 — kareeb, lekin exact nahi.

Problem: 1,000 parameters ke liye 1,001 function evaluations chahiye — bahut slow. Aur numerical error bhi hoti hai. Isliye finite differences sirf testing ke liye hai, training ke liye nahi.

B.3 Forward-Mode Autodiff

Forward-mode: example g = 5 + xy, ∂g/∂x = y. Dual numbers istemal karo: a + bε jahan ε²=0 — to h(a+ε) = h(a) + h′(a)ε. Matlab function value ke saath derivative bhi mil jata hai, ek hi pass me.

Problem: 1,000 parameters ke liye 1,000 passes chahiye — har input ke liye ek pass. Jab outputs kam aur inputs zyada hon (jaise neural networks me), to forward-mode slow hai.

B.4 Reverse-Mode Autodiff

Reverse-mode: do passes — pehle forward (values compute karo), phir backward (chain rule se gradients wapas bhejo). Example me intermediate values: n7=42, ∂f/∂n5=1, ∂f/∂n4=4.

TensorFlow symbolic reverse-mode autodiff istemal karta hai — yehi backpropagation hai. Reverse-mode ko sirf do passes chahiye chahe kitne bhi parameters hon — isliye neural networks ke liye yehi sahi hai. Custom operation ke liye derivative dena padta hai — jaise f=x² ke liye f′=2x.

python
import tensorflow as tf

x = tf.Variable(3.0)
with tf.GradientTape() as tape:
    f = x ** 2  # f = 9
print(tape.gradient(f, x))  # 6.0  (f' = 2x)

Ek graph me ops hote hain — [Placeholder x, Const pow/y, Pow, Identity] — aur tensors ke naam hote hain x:0, pow:0, Identity:0. Function_def signature hoti hai __inference_tf_cube_3515903 with DT_FLOAT.

python
@tf.function
def tf_cube(x):
    return x ** 3

print(tf_cube(2.0))  # 8.0
print(tf_cube(5))    # 125
concrete = tf_cube.get_concrete_function(tf.TensorSpec(shape=[], dtype=tf.float32))

D.2 Tracing and AutoGraph

Tracing me Python function ek baar chalti hai symbolic tensors ke saath, aur graph ban jata hai. Python values se har value par retrace hota hai — isliye input_signature se bachao: TensorSpec([None, 28, 28], float32) se retracing rukti hai.

Python range statically unroll hota hai — 10 AddV2 ops ban jate hain; tf.range dynamic StatelessWhile loop deta hai. Resources DT_RESOURCE tensors hote hain — jaise assign_add wala counter. Python variable ko TF function ke andar assign nahi kar sakte.

AutoGraph Python control flow (for, if) ko TensorFlow ops me badal deta hai — isliye @tf.function me normal Python likh sakte ho, aur wo graph ban jata hai.

D.3 Using TF Functions

TF functions ko sahi tareeke se istemal karo: input_signature do taaki retracing na ho; Python side-effects se bacho; debugging ke liye Keras dynamic=True / run_eagerly=True se eager mode me chalao.

Interview FAQs


Hands-On ML par interview me sabse zyada poochhe jaane wale 36 sawaal — har jawaab is book ke content par based hai.




01Machine Learning kya hai, aur traditional programming se kaise alag hai?
Machine Learning computer science ka wo field hai jo computers ko bina explicitly program kiye data se seekhne ki ability deta hai. Traditional programming me programmer rules likhta hai aur data daal kar answers nikalta hai; ML me data aur answers daal kar rules nikale jate hain. Spam filter iska classic example hai — rules likhne ke bajaye filter ko spam aur non-spam ke examples dikhao, wo khud pattern seekh lega. ML wahan jeet-ta hai jahan rules likhna mushkil ho, rules badalte rehte hon, data bahut bada ho, ya system ko naye data se adapt karna ho.


02Supervised, unsupervised, semisupervised, self-supervised aur reinforcement learning me farak kya hai?
Farak training data aur feedback me hai. Supervised learning labelled data istemal karta hai — classification aur regression iske kaam hain. Unsupervised learning unlabelled data par kaam karta hai — clustering, dimensionality reduction aur anomaly detection. Semisupervised me thoda labelled aur bahut saara unlabelled data hota hai. Self-supervised me labels data se hi bante hain — jaise agla word predict karna. Reinforcement learning me environment se reward signal milta hai — agent reward maximise karna seekhta hai, jaise game khelna. Interview me ek line me jawaab do: labels hain ya nahi, aur feedback kaisa hai.


03Instance-based aur model-based learning me kya farak hai?
Instance-based learning training examples ko yaad rakhta hai aur naye example ki prediction similarity se karta hai — k-nearest neighbours iska example hai. Model-based learning data se ek model banata hai, jaise ek line ya equation, aur prediction us model se karta hai — training ke baad data ki zaroorat nahi padti. Model-based algorithms parameter values dhoondhte hain jo ek cost function ko minimise karte hain. Instance-based ko training me kuch nahi karna padta lekin prediction slow hoti hai; model-based ko training me mehnat karni padti hai lekin prediction tez hoti hai.


04Overfitting aur underfitting kya hain, aur inhe kaise pehchanein aur theek karein?
Overfitting matlab model training data ko rat leta hai aur naye data par fail hota hai — training error kam, validation error zyada, dono ke beech gap. Underfitting matlab model bahut simple hai aur pattern hi nahi pakad pata — dono errors upar hain aur kareeb hain. Learning curves se pehchano: dono curves upar plateau karein to underfitting, gap ho to overfitting. Overfitting ke solutions: zyada data, regularisation (Ridge/Lasso/dropout), early stopping, ya simple model. Underfitting ke solutions: zyada complex model, zyada features, ya kam regularisation.


05Test set, validation set aur cross-validation ka kya kaam hai?
Test set wo data hai jo model ne kabhi dekha hi nahi — usi se asli performance naapi jati hai, aur use sirf end me ek baar chhoo. Validation set hyperparameters tune karne ke liye hota hai — model selection ke liye. Cross-validation data ko kai hisson me baant kar har baar ek hissa test ke liye istemal karta hai aur average leta hai — isse generalisation ka andaza zyada reliable hota hai. Data snooping se bacho — test set ko baar-baar dekh kar usi ke hisaab se model badalna matlab test set bhi training set ban jana.


06California housing project me stratified sampling kyun istemal ki gayi thi?
Stratified sampling se test set me income distribution full data jaisi hi rehti hai. Data ko income category ke hisaab se baanta gaya (bins 0, 1.5, 3.0, 4.5, 6.0, infinity) aur har category se proportionally sample liya gaya. Test-set proportions categories 1–5 ke liye 16.39%, 27.04%, 35.05%, 11.74%, 9.78% mile — full data ke 16.23%, 27.12%, 35.07%, 11.70%, 9.88% ke bahut kareeb. Random split se aisa guarantee nahi milta — test set biased ho sakta tha, aur performance ka andaza galat ho jata.


07Feature scaling kab zaroori hai aur kab nahi?
Scaling gradient-descent aur distance-based models ke liye zaroori hai — jaise linear regression with GD, SVM, k-NN aur neural networks — kyunki bade scale wale features dominate karne lagte hain. Tree-based models (decision tree, random forest, gradient boosting) ko scaling se farak nahi padta kyunki wo thresholds par split karte hain. MinMaxScaler values ko 0–1 me lata hai, StandardScaler mean 0 aur std 1 karta hai. California housing me scaling ke baad hi SGD multiclass accuracy 0.87 se 0.90 tak badhi thi.


08Pipeline aur ColumnTransformer kyun istemal karte hain?
Pipeline preprocessing aur model ko ek unit me bandhta hai — isse data leakage rukta hai aur code clean rehta hai. ColumnTransformer alag columns par alag transformations lagata hai — jaise numeric par impute + scale, categorical par one-hot encode. California housing me ColumnTransformer + Pipeline se 24 features bane (8 numeric + 1 cluster-similarity + 10 RBF + 5 one-hot). Pipeline ke bina cross-validation me preprocessing galat ho jata hai — jaise poore data par scaler fit karna, jo leakage hai. Pipeline se har fold me preprocessing sirf training data par fit hoti hai.


09Accuracy kab misleading hoti hai? Precision, recall aur F1 kya hain?
Imbalanced data par accuracy misleading hoti hai — MNIST 5-detector me dummy classifier jo hamesha 'not-5' kahe, uski accuracy 90.965% hai bina kuch seekhe. Confusion matrix dekho: TP 3,530, FP 687, FN 1,891, TN 53,892. Precision = TP/(TP+FP) = 0.837 — jab model '5' kahe to kitni baar sahi. Recall = TP/(TP+FN) = 0.651 — asal 5s me se kitne pakde. F1 = 2·precision·recall/(precision+recall) = 0.7325 — dono ka harmonic mean. Spam filter me precision matter karta hai, cancer detection me recall — kaunsa metric chahiye, ye business par depend karta hai.


10Precision/recall tradeoff kya hai, aur ROC curve kya batata hai?
Decision threshold badhao to precision badhta hai aur recall girta hai. MNIST 5-detector me threshold 3,000 par precision 90% ho jata hai lekin recall 48% reh jata hai; 90% precision ke liye threshold 3,370.02 chahiye. ROC curve true positive rate vs false positive rate dikhata hai aur AUC uska area hai — AUC 1.0 perfect hai, 0.5 random hai. SGD classifier ka AUC 0.96049 tha, RandomForest ka 0.99834 — F1 0.9242, precision ~99.1%, recall 86.6%. ROC threshold se independent comparison deta hai, isliye models compare karne me useful hai.


11Normal Equation aur Gradient Descent me kaunsa kab chunein?
Normal Equation θ = (XᵀX)⁻¹Xᵀy se ek hi step me solution milta hai — chhote data par tez aur exact hai. Lekin iski complexity O(n²·⁴–n³) hai, isliye bade features par slow ho jata hai. Gradient descent iterative hai — batch GD poora data ek saath, SGD ek example at a time, mini-batch GD beech ka rasta. Batch GD η=0.1, 1,000 epochs se Normal Equation wala hi θ [4.215, 2.770] milta hai. Bade data ya online learning ke liye GD chuno; chhote data aur exact solution ke liye Normal Equation ya SVD chuno.


12Ridge, Lasso aur Elastic Net me kya farak hai?
Teeno regularisation hain — bade weights par penalty lagate hain taaki overfitting ruke. Ridge (L2) cost me α/m·Σθ² jodta hai — weights ko chhota karta hai lekin zero nahi. Lasso (L1) 2α·Σ|θ| jodta hai — kuch weights ko exactly zero kar deta hai, isliye sparse models aur automatic feature selection milti hai. Elastic Net dono ko ratio r se mix karta hai. Alpha=0.1 par x=1.5 ki prediction: Ridge 1.553, Lasso 1.538, Elastic Net 1.543. Feature selection chahiye to Lasso, sirf shrinkage chahiye to Ridge, dono chahiye to Elastic Net.


13Logistic regression kya hai, aur softmax regression kaise kaam karta hai?
Logistic regression naam me regression hai lekin classification karta hai — linear combination ko sigmoid σ(t) = 1/(1+e^(−t)) se probability me badalta hai, aur log loss (cross-entropy) se train hota hai. Iris par virginica classifier ki decision boundary petal width 1.6517 cm par hai — 1.7 ho to virginica, 1.5 ho to nahi. Softmax regression multiclass ke liye hai: har class ka score s_k = xᵀθ⁽ᵏ⁾, phir softmax se probabilities. C=30 ke saath input [5, 2] se virginica ki probability 96% aur versicolor ki 4% mili.


14SVM me soft margin aur C ka kya matlab hai?
SVM classes ke beech sabse chaudi street (margin) dhoondhta hai; street ke kinare wale instances support vectors hote hain. Hard margin me koi violation allowed nahi; soft margin me violations allowed hain aur C unhe control karta hai — chhota C matlab chaudi street aur zyada violations, bada C matlab patli street aur kam violations. Iris par C=1 vs C=100 ka farak saaf dikhta hai. SVM feature scales ke prati sensitive hai, isliye scaling zaroori hai. LinearSVC me predict_proba nahi hota — probability chahiye to SVC with probability=True istemal karo.


15Kernel trick kya hai, aur RBF kernel me gamma kya karta hai?
Kernel trick transformed features ko explicitly compute kiye bina unka dot product nikaal leta hai — jaise polynomial kernel me φ(a)ᵀφ(b) = (aᵀb)². Isse high-dimensional space me kaam karna sasta ho jata hai. Gaussian RBF kernel similarity landmarks se naapta hai — x=−1 ke liye similarities 0.74 aur 0.30 mili thin. Gamma width control karta hai: bada gamma matlab patla, irregular decision boundary; chhota gamma matlab smooth boundary. Polynomial degree 10 overfit kar deta hai, isliye degree aur gamma dono tune karne chahiye.


16Decision tree kaise train hota hai, aur Gini vs entropy me kya farak hai?
CART algorithm greedy hai — har node par wo split chunta hai jo weighted impurity sabse zyada kam kare. Optimal tree dhoondhna NP-complete hai (O(exp(m))), isliye greedy hi practical hai. Training complexity O(n·m·log₂ m), prediction O(log₂ m). Gini impurity aur entropy dono similar results dete hain — Gini thoda faster hai aur frequent class ko isolate karne ki taraf jhukta hai. Iris tree me root petal length ≤ 2.45 par split karta hai, right node petal width ≤ 1.75 par. Depth-2 left node ki Gini ≈ 0.168 aur entropy ≈ 0.445 thi.


17Voting, bagging, boosting aur stacking me kya farak hai?
Voting me kai classifiers ki ray li jati hai — hard voting majority se, soft voting probabilities ke average se. Bagging me har model ko data ka random subset milta hai — 500 trees, max_samples=100. Boosting me models sequence me train hote hain aur har naya model pichhle ki galtiyan theek karta hai — AdaBoost weights badhata hai, gradient boosting residuals par fit hota hai. Stacking me ek meta-learner base learners ki out-of-fold predictions se seekhta hai ki kis par kab bharosa karna hai. Moons par soft voting 0.92, stacking 92.8% — har method ka apna trade-off hai.


18AdaBoost aur Gradient Boosting kaise kaam karte hain?
AdaBoost galat classify hue instances ka weight badhata hai — α = η·log((1−r)/r) jahan r weighted error rate hai, aur galat instances ka weight ×exp(α) ho jata hai. Example me 30 stumps, learning_rate=0.5 istemal hue. Gradient boosting har naya tree pichhle ensemble ke residual errors par fit karta hai — y=3x²+noise 0.05 par teen depth-2 trees se predictions [0.495, 0.040, 0.750] mili thin. Learning rate (shrinkage) har tree ka contribution control karta hai; early stopping n_iter_no_change=10 se 92 trees mile. HistGradientBoosting max_bins=255 ke saath tez hai aur categorical features aur missing values handle karta hai.


19Curse of dimensionality kya hai, aur PCA kaise madad karta hai?
Dimensions badhne par data space itna bada ho jata hai ki data sparse ho jata hai — 10,000-dimensional hypercube me >99.999999% points border ke 0.001 ke andar hote hain, jabki 2D me sirf 0.4%. 100 dimensions me density 0.1 paane ke liye universe ke atoms se zyada samples chahiye honge. PCA SVD se maximum variance wali directions dhoondhta hai aur data ko un par project karta hai. MNIST par 95% variance bachane ke liye 154 components chahiye (784 me se) — 5× compression. Pehle do components ki explained variance ratio 0.758/0.152 thi.


20Gaussian Mixture Models K-Means se kaise alag hain?
GMM har cluster ko ek Gaussian distribution manta hai aur soft assignments deta hai — har point har cluster se kuch probability ke saath juda hota hai. EM algorithm se train hota hai aur 4 iterations me converge hua tha. Example me weights [0.39, 0.40, 0.21] mile (true 0.4, 0.4, 0.2). GMM se naye samples generate kar sakte ho aur anomaly detection kar sakte ho — density ke 2nd percentile se neeche wale points anomalies hain. Clusters ki ginti ke liye BIC aur AIC dekho — dono k=3 par minimum the (BIC 8,189.7, AIC 8,102.5). Bayesian GMM khud tay karta hai kitne clusters chahiye.


21Perceptron XOR kyun solve nahi kar sakta, aur MLP kaise karta hai?
Single perceptron sirf linearly separable problems solve kar sakta hai — wo ek seedhi line se classes ko alag karta hai. XOR linearly separable nahi hai, isliye ek perceptron use solve nahi kar sakta. MLP me hidden layers hoti hain jo nonlinear transformations seekhti hain — pehli layer naye features banati hai jin par doosri layer seedhi line se alag kar sakti hai. Backpropagation se MLP train hota hai — gradients ko peeche bhej kar har layer ke weights update kiye jate hain. Random initialisation zaroori hai warna saare neurons ek jaisa seekhte hain.


22Fashion MNIST par MLP vs CNN — CNN kyun behtar hai?
MLP Fashion MNIST par 88.58% test accuracy deta hai (30 epochs ke baad, train 92.04%, validation 89.04%). CNN >92% deta hai — Conv2D 64 (7×7) / 128 / 128 / 256 / 256, Dense 128 / 64, dropout 0.5 ke saath. CNN behtar hai kyunki convolution local patterns (edges, textures) seekhta hai aur weight sharing se parameters kam hote hain — 200 filters 5×5 par sirf 15,200 parameters. MLP har pixel ko alag feature manta hai aur spatial structure ignore karta hai. Images ke liye CNN hi sahi choice hai.


23Vanishing gradient problem kya hai, aur batch normalization kaise madad karta hai?
Gehre networks me gradients pehli layers tak pahunchte-pahunchte zero ke kareeb ho jate hain (vanish) ya bahut bade ho jate hain (explode) — training ruk jati hai. Solutions: He/Glorot initialisation, nonsaturating activations (ReLU, ELU, SELU), batch normalization aur gradient clipping. Batch norm har layer ke inputs ko normalise karta hai (μ=0, σ=1, phir γ⊗x̂+β se seekhta hai) — ImageNet top-5 error 4.9% validation par 14× fewer steps me mila. BN parameters example me 3,136+1,200+400 the, total 271,346 me se.


24Transfer learning kya hai, aur fine-tuning kaise karte hain?
Transfer learning matlab pretrained model ko apne task par istemal karna — scratch se train karne ke bajaye pehle se seekhi hui features reuse karo. Example: 8 classes wala model >90% tha; sirf 200 images wale model B ko transfer se 91.85% se 93.85% tak le jaya gaya — error 25% kam hui. Tareeka: pehle base frozen rakho aur sirf top layers train karo, phir dheere-dheere neeche ki layers unfreeze karo kam learning rate se. Flowers dataset par Xception frozen se validation >80% mili, layers[56:] unfreeze karke test ~92% ho gaya. Warning: test data se pretrained model chunna cheating hai.


25Adam, RMSProp aur SGD me kaunsa optimizer chunein?
SGD with momentum (β=0.9) simple aur reliable hai — Nesterov (NAG) usse behtar hai kyunki wo pehle aage badh kar gradient naapta hai. AdaGrad har parameter ka apna learning rate rakhta hai lekin jaldi ruk jata hai. RMSProp (ρ=0.9) AdaGrad ka fix hai. Adam momentum aur RMSProp dono ko combine karta hai (β1=0.9, β2=0.999, ε=1e-7) aur aksar default choice hota hai. Adam ke saath L2 mat lagao — AdamW istemal karo (decoupled weight decay). Learning rate scheduling bhi matter karta hai — 1cycle se CIFAR-10 par 91.9% sirf 100 epochs me mila, jabki bina schedule ke 90.3% ke liye 800 epochs lage.


26Dropout kya hai, aur MC dropout se uncertainty kaise milti hai?
Dropout training me random neurons ko band kar deta hai (p=10–50% — RNNs ke liye 20–30%, CNNs ke liye 40–50%) — isse network ek hi neuron par depend nahi karta aur 2^N possible networks ka ensemble banta hai, jisse 1–2% accuracy boost milta hai. Test time par outputs ko keep probability se divide karo. MC dropout me test time par bhi dropout on rakh kar 100 samples lete hain — predictions ka spread uncertainty batata hai. Fashion MNIST pehli image par confidence 84.4% se 72.3% ho gaya (sandal 6.7%, sneaker 20.9%, std 0.183) — model ko pata hai ki wo kitna unsure hai.


27tf.function kya hai, aur retracing se kaise bachein?
@tf.function Python function ko TensorFlow graph me badal deta hai — isse execution tez hota hai aur XLA jit_compile se ops fuse ho jate hain. Lekin har naye input shape/dtype par naya graph banta hai (polymorphism), aur Python values se har value par retrace hota hai — ye graph explosion hai. Bachne ke liye input_signature do, jaise TensorSpec([None, 28, 28], float32). Rules yaad rakho: variables sirf pehli call par bante hain, tf.range istemal karo range ki jagah, np.random.rand har trace me same value deta hai, aur py_function optimisation rok deta hai. Debugging ke liye run_eagerly=True se eager mode me jao.


28CNN me convolution aur pooling kaise kaam karte hain?
Convolution me ek chhota filter (kernel) image par slide karta hai aur har jagah dot product leta hai — har filter ek pattern dhoondhta hai, jaise edge ya texture. Example: 32 filters 7×7 on 70×120×3 images se valid padding par [2, 64, 114, 32] milta hai, same padding par 70×120×32. Pooling (max pooling 2×2 stride 2) feature maps ko aadha kar deta hai aur invariance deta hai — object thoda shift ho jaye to bhi pehchan me aaye. GlobalAveragePooling2D poori feature map ka mean deta hai. Parameters kam hote hain lekin activations zyada — memory ka dhyaan rakho.


29ResNet me residual connections kyun kaam karte hain?
Gehre networks me gradients vanish ho jate hain — residual connection f(x) = h(x) − x se gradient seedha peeche beh sakta hai, layers ko skip karke. Isse 152 layers tak ke networks train ho jate hain — ResNet ki top-5 error <3.6% thi. ResNet-34 me 3×64, 4×128, 6×256, 3×512 residual units hain. Keras me ResidualUnit class se banaya jata hai — jab strides>1 ho to 1×1 convolution se shortcut ko match karo. Residual connections ke bina itne gehre networks train hi nahi hote.


30RNN, LSTM aur GRU me kya farak hai?
Simple RNN me state h(t)=f(x, h(t−1)) hota hai — lekin lambi sequences par gradients vanish ho jate hain. LSTM (1997) me input/forget/output gates hote hain aur cell state lambi memory rakhta hai — forget-gate bias 1 se initialise karo. GRU (2014) me update/reset gates hote hain aur state merged hota hai — LSTM se simple hai aur aksar similar result deta hai. Chicago ridership par SimpleRNN 1 neuron se MAE >100,000 tha, 32 neurons + Dense se 27,703 ho gaya, multivariate se 22,062. WaveNet dilated convolutions (1, 2, 4, …, 512) se lambi dependencies pakadta hai.


31Attention mechanism kya hai, aur Transformer RNN se behtar kyun hai?
Attention me decoder har output word ke liye input ke relevant hisse par dhyaan deta hai — additive attention (2014) aur dot-product attention (2015) do variants hain. Transformer (2017) me N=6 layers, positional encoding sin/cos, aur scaled dot-product attention softmax(QKᵀ/√d)V hota hai — multi-head attention 8 heads ke saath. Transformer RNN se behtar hai kyunki wo parallel train hota hai aur lambi dependencies behtar pakadta hai — RNN ko sequence step-by-step chalni padti hai. Isi liye aaj ke bade models Transformer par bane hain.


32BERT aur GPT me kya farak hai?
Dono Transformer par bane hain lekin training alag hai. GPT generative hai — agla word predict karke train hota hai (12 layers, 2018) aur text generate karne me achha hai. BERT masked language modelling se train hota hai — 15% tokens mask karo (80/10/10 replacement) aur context se predict karo, plus next-sentence prediction — aur understanding tasks (classification, question answering) me achha hai. GPT-2 1.5B parameters ka tha, PaLM 540B parameters aur 6,000 TPUs par train hua. Dono ke baad chain-of-thought prompting aayi — model ko step-by-step sochne ko kaho to reasoning behtar hoti hai.


33Autoencoder, VAE aur GAN me kya farak hai?
Autoencoder input ko compress karke wapas banata hai — bottleneck se representation seekhta hai; linear autoencoder PCA ke barabar hota hai. VAE (2013) encoder se μ aur σ nikalta hai aur latent vector sample karta hai — isse naye samples generate kar sakte ho aur latent space me interpolation kar sakte ho (pants se sweaters). GAN (2014) me generator fake data banata hai aur discriminator asli vs nakli pehchanta hai — dono ek doosre se seekhte hain. GAN ki training mushkil hai — mode collapse hota hai, isliye RMSProp istemal karo, Nadam nahi. Diffusion models (T=4,000 steps) aaj sabse behtar quality dete hain lekin slow hain.


34Reinforcement learning me policy gradients aur Q-learning me kya farak hai?
Policy gradients policy ko seedha optimise karte hain — REINFORCE me achhe actions ki probability badhao aur bure ki ghatao; training 150 iterations × 10 episodes × 200 steps, γ=0.95, Nadam lr=0.01 se hui thi. Q-learning action-values seekhta hai — TD error δ = r + γ·max Q(s′, a′) − Q(s, a) se Q-values update karo; α0=0.05, decay 0.005, γ=0.90, 10,000 iterations. DQN Q-function ko neural network se represent karta hai — replay buffer 2,000, batch 32, γ=0.95, 600 episodes, target network har 50 episodes me clone karo. Double DQN overestimation kam karta hai, dueling DQN value aur advantage alag seekhta hai.


35TensorFlow Serving aur TensorFlow Lite me kaunsa kab chunein?
TensorFlow Serving server par models serve karta hai — ports 8500 (gRPC) aur 8501 (REST), versioned models, graceful rollout aur batching ke saath. Fashion MNIST par image 7 ~100%, image 2 99%, image 1 97% confidence se predict hui. TensorFlow Lite mobile aur embedded devices ke liye hai — FlatBuffers format, post-training quantisation se 4× chhota model (−1.5…+0.8 ko −127…127 me map karo). Server par Serving, phone par Lite, browser me TensorFlow.js — use case ke hisaab se chuno. Vertex AI cloud par training aur tuning ke liye hai — 100 trials, 20 parallel me best trial 98% accuracy par pahuncha.


36Autodiff kya hai, aur forward-mode vs reverse-mode me kya farak hai?
Autodiff derivatives ko exact tareeke se compute karta hai — numerical approximation nahi. Forward-mode dual numbers istemal karta hai (a + bε, ε²=0) — lekin 1,000 parameters ke liye 1,000 passes chahiye. Reverse-mode do passes me kaam karta hai — pehle forward me values, phir backward me chain rule se gradients — chahe kitne bhi parameters hon. Isliye neural networks reverse-mode istemal karte hain — yehi backpropagation hai. Example: f = x²y + y + 2 ke gradients (3, 4) par 24 aur 10 hain; finite differences se 24.00004 aur 10.00000000033 mile the — kareeb lekin exact nahi.
