Ch 1 — Foundations of Agentic AI Systems

AI agent kya hai, chatbot se kaise alag hai, agentic loop kaise chalta hai, aur kaun si architectures aur frameworks aaj kaam aate hain — is chapter me poori buniyaad hai.

1.1 Understanding Agentic AI — agent kya hota hai

AI agent ek aisa system hai jo apne environment ko perceive karta hai, jo dekhta hai us pe reasoning karta hai, actions choose karta hai, tools use karta hai, aur results se seekhta hai — ek goal ke peeche kai steps tak chalta hai, ek prompt ka jawaab deke rukta nahi.

Assistant se agent tak ka safar reactive replies se autonomous, multi-step kaam ki taraf hai — memory, planning aur tool use ke saath. Chatbot conversational aur zyada tar stateless hota hai; agent goal-directed, stateful aur tool-using hota hai.

1.1.3 The Agentic Loop — chaar kadam, baar-baar

Agentic loop chaar kadam ka cycle hai: perception (environment ko dekhna), reasoning / planning (kya karna hai sochna), action (tool chalana ya kadam uthana), phir observation (result dekhna) — aur ye tab tak repeat hota hai jab tak goal poora na ho ya koi limit na aa jaye.

Orchestrator–workers model me ek central planner kaam baant-ta hai aur results ko jodta hai.

Ch 2 — Retrieval-Augmented Generation (RAG), Agentic RAG, aur Model Context Protocol (MCP)

Model ko training data pe bharosa karne ke bajay retrieved documents se ground karo — RAG ka yehi idea hai. Phir uspe agent aur MCP ki layer aati hai.

2.1 What Is Retrieval-Augmented Generation? — RAG kaise kaam karta hai

RAG me query ko embed kiya jata hai, vector store se similar passages retrieve hote hain, aur wo passages prompt me daal diye jate hain — taaki answer current, organisation-specific material pe based ho aur hallucination kam ho. Chaar stages hain: ingestion / chunking, embedding, retrieval, aur generation.

Benefits: freshness, grounding, source attribution, aur retraining se bachna. Fine-tuning se farak: fine-tuning knowledge ko weights me bake karta hai (style/behaviour ke liye achha, expensive, update slow); RAG knowledge ko bahar rakhta hai aur updatable rakhta hai (badalte facts ke liye achha).

↓

Ch 3 — Protocols for the Internet of Agents

Agents ko shared protocols chahiye — bilkul waise hi jaise web ko HTTP chahiye tha. Warna har vendor ke agents ek-doosre ko dhoondh, trust ya baat nahi kar sakte.

3.1 Agent Communication Protocols — kyun chahiye

MCP agent ko tools aur data se jodta hai (client–server, resources/prompts/tools). A2A agent-to-agent hai: agents apni 'agent card' publish karte hain — skills, endpoint aur authentication — task messages exchange karte hain, updates stream karte hain, aur long-running, multi-turn tasks support karte hain. ANP decentralised, web-like approach hai — agents ke decentralised identifiers (DIDs) hote hain, metadata publish karte hain, aur HTTP + JSON-LD pe communicate karte hain. ACP REST-based, asynchronous protocol hai — multipart messages ke saath agent-to-agent communication ke liye.

FAQs — 36 Interview Questions

Agentic AI aur cybersecurity pe interview me poochhe jaane wale sawaal — har jawaab book ke content se hai.

1AI agent aur chatbot me asal farak kya hai?
Chatbot conversational aur zyada tar stateless hota hai — ek sawaal ka jawaab deke ruk jata hai. Agent goal-directed, stateful aur tool-using hota hai: wo perceive karta hai, plan karta hai, tools chalata hai, results observe karta hai, aur goal poora hone tak loop me chalta hai.
2Agentic loop ke chaar kadam kaun se hain?
Perception (environment ko dekhna), reasoning / planning (kya karna hai), action (tool chalana ya kadam uthana), aur observation (result dekhna). Ye cycle goal poora hone ya limit aane tak repeat hoti hai.
3ReAct pattern kya hai aur ye kyun useful hai?
ReAct reasoning traces ko tool actions ke saath interleave karta hai — model sochta hai, action leta hai, observe karta hai, aur apni soch revise karta hai. Isse agent galat raaste pe jaake bhi wapas sahi ho sakta hai, kyunki har action ka result agle thought me aata hai.
4Single-agent aur multi-agent architecture me kaise choose karein?
Single-agent simple kaam ke liye — low complexity, limited scale. Multi-agent tab jab kaam specialised parts me bat sakta ho — triage, investigation, response alag agents. Trade-off: multi-agent me coordination cost aur debugging mushkil hoti hai.
5Orchestrator–workers model kaise kaam karta hai?
Ek central planner (orchestrator) kaam ko baant-ta hai, specialised workers apna hissa karte hain, aur orchestrator results ko jod ke final answer deta hai. Ye hierarchical orchestration ka ek form hai.
6RAG aur fine-tuning me kab kisko chunna chahiye?
RAG jab facts badalte rehte hain aur grounding chahiye — knowledge bahar, vector store me, fast update. Fine-tuning jab style, behaviour ya tone bake karna ho — expensive, slow update. Aksar dono ek saath use hote hain.
7Chunking me overlap kyun rakha jata hai?
Chunking lambe documents ko passages me todti hai. Overlap isliye taaki chunk ke boundary pe context na toote — ek chunk ke end aur agle ke start me same lines hon, to retrieval me meaning poori mile.
8Vector database kaise kaam karta hai?
Embeddings dense numeric vectors hote hain jo meaning capture karte hain. Vector database in vectors ko store karta hai aur query ke embedding se similarity search karke sabse relevant passages lauta deta hai. Examples: Chroma, FAISS, Pinecone, Weaviate, Qdrant, Milvus.
9Agentic RAG normal RAG se kaise alag hai?
Normal RAG ek baar retrieve karke answer deta hai. Agentic RAG me agent decide karta hai — retrieve karna hai ya nahi, query rewrite karni hai, kaun sa source use karna hai, kai rounds chalane hain, answer verify karna hai, ya evidence thin ho to escalate karna hai.
10MCP kya hai — ek line me?
Model Context Protocol ek standard hai jisse agent external tools aur data ko discover aur call kar sakta hai — host, client aur servers ke pattern me, JSON-RPC pe. Servers resources (data), prompts (templates) aur tools (functions) expose karte hain.
11MCP server ko secure kaise karte hain?
Least privilege — server ko sirf wahi tools do jo chahiye; allow-listing — sirf approved tools; tool descriptions aur outputs ko validate karo; sandboxing; aur server content ko hamesha untrusted data samjho, instruction nahi.
12A2A, ANP aur ACP me farak kya hai?
A2A agent-to-agent tasks ke liye hai — agent card publish karo, task messages bhejo, updates stream karo. ANP decentralised web-like approach hai — DIDs aur registry se discovery. ACP REST-based async protocol hai multipart messages ke saath. MCP in sabse alag hai — wo agent-to-tool/data ke liye hai, agent-to-agent ke liye nahi.
13Agent card kya hoti hai aur isme spoofing ka risk kyun hai?
Agent card ek agent ki public description hoti hai — skills, endpoint, authentication. Agar card spoof ho jaye to ek malicious agent trusted agent banke task le sakta hai. Isliye signed metadata aur verification zaroori hai.
14LangChain, LangGraph aur LlamaIndex — teeno kab use karein?
LangChain chaining, prompts aur tools ke liye. LangGraph stateful graph workflows ke liye — jahan checkpoints, persistence aur human-in-the-loop approval chahiye. LlamaIndex data indexing aur retrieval ke liye — documents ko model se jodna. Aksar teeno ek system me saath use hote hain.
15LCEL kya hai?
LangChain Expression Language — declarative pipe syntax. Prompt | model | output parser likh ke chain banao. Ye readable hota hai aur components ko aasani se compose karne deta hai.
16LangGraph me state kyun important hai?
State ek shared typed dictionary hai jo har node dekh aur update kar sakta hai. Isse agent ko yaad rehta hai kya ho chuka hai, loops aur branching possible hote hain, aur checkpoints se run ko pause/resume kiya ja sakta hai.
17Human-in-the-loop ka matlab kya hai, practically?
Agent consequential step se pehle rukta hai aur insaan se approval leta hai — jaise host isolate karna, data delete karna, ya paise kharch karna. Low confidence pe bhi case insaan ko escalate hota hai.
18CrewAI me crew, agent aur task ka relation kya hai?
Agent ek role hota hai (role, goal, backstory). Task ek kaam hota hai expected output ke saath. Crew agents aur tasks ka collection hai jo ek process flow (sequential, hierarchical ya parallel) me chalta hai.
19n8n aur Airflow me kab kisko chunna chahiye?
n8n jab visual, low-code flows chahiye aur integrations jaldi jodni hon. Airflow jab scheduled, repeatable, auditable pipelines chahiye — DAGs ke saath retries aur monitoring. n8n quick automation, Airflow scheduled production pipelines.
20SOC me agent ki sabse badi value kya hai?
Speed aur scale. SOC roz 10,000–100,000 alerts dekhta hai; agent seconds me triage, enrich aur investigate karta hai — book ke case studies me 3 AM alert lagbhag 28 seconds me close hua aur ransomware containment recommendation lagbhag 27 seconds me aayi.
21SOC agent me reliability kaise ensure hoti hai?
Confidence thresholds, guardrails, audit logging, aur escalation. Confidence low ho ya action irreversible ho — case insaan ke paas jata hai. Testing synthetic alerts pe hoti hai — precision, recall aur time-to-triage measure karke.
22Breakout time kya hai aur ye SOC ke liye kyun matter karta hai?
Breakout time initial access se lateral movement tak ka time hai — minutes me measure hota hai. Agar triage slow hai to attacker tab tak phail chuka hota hai. Isliye SOC me seconds matter karte hain.
23Agentic penetration testing aur traditional testing me farak kya hai?
Traditional testing periodic, manual aur point-in-time hoti hai. Agentic testing continuous, autonomous aur adaptive hai. Lekin dono me scope aur rules of engagement likhe hue hone chahiye — bina permission ke scan ya exploit illegal hai.
24Red teaming aur penetration testing me farak kya hai?
Penetration testing ek system ki vulnerabilities dhoondhti hai. Red teaming broad hoti hai — real adversary simulate karti hai across people, process aur technology, authorised hone pe phishing aur social vectors bhi.
25Bug bounty me agent kya karta hai?
Agent in-scope targets ko continuously probe karta hai, duplicates triage karta hai, aur reports draft karta hai. Payout aur disclosure rules waise hi rehte hain — agent sirf hunting automate karta hai, rules nahi badalta.
26Prompt injection direct aur indirect me farak kya hai?
Direct injection me attacker seedha prompt me malicious instruction daalta hai. Indirect me instruction retrieved document, web page ya tool output me chhupa hota hai — agent use padh ke follow kar leta hai. Dono se bachne ke liye input/output validation aur guardrails chahiye.
27Tool misuse ka ek example do.
Agent ko aise tool call karne pe trick karna jo dangerous ho — jaise file delete, ya tools ko chain karke unintended effect — jaise pehle data read karo phir use bahar bhejo. Mitigation: least privilege, allow-listing, aur consequential actions pe approval.
28Rogue agent kya hota hai?
Wo agent jo apne mandate se bahar kaam kare — persistently ya compromise ke baad. Jaise agent ko triage ka kaam diya gaya ho aur wo khud containment actions lene lage. Isliye monitoring, audit logs aur behaviour limits zaroori hain.
29OWASP ASI01–ASI10 kya hai?
OWASP Agentic AI threats ki list hai: ASI01 trust/identity, ASI02 tool misuse, ASI03 identity/privilege abuse, ASI04 spoofing/impersonation, ASI05 unexpected code execution (RCE), ASI06 memory/context poisoning, ASI07 insecure inter-agent communication, ASI08 cascading agent failure, ASI09 misaligned/deceptive behaviour, ASI10 rogue agents.
30Cascading agent failure kya hai?
Jab ek agent ki galti ya compromise doosre agents me phail jaye — jaise ek agent ka galat output doosre agent ke input me jaye aur wo bhi galat decision le. Isliye har agent ke output ko validate karo aur failure ko isolate karo.
31Memory poisoning kaise hota hai?
Agent ki memory ya context me malicious content daal diya jaye — jaise poisoned document retrieve ho ke memory me save ho jaye — aur baad me agent usi poisoned context pe decisions le. Mitigation: source validation aur memory writes pe checks.
32NIST AI RMF ke chaar functions kaun se hain?
Govern, Map, Measure, Manage. Govern — policies aur accountability. Map — risks ko samjho. Measure — risks ko measure karo. Manage — risks ko manage aur monitor karo.
33Google SAIF ke six functions kya hain?
Expand security foundations, extend detection, automate defences, harmonise controls, contextualise risk, aur adapt. Ye AI systems ke liye security ko end-to-end cover karta hai.
34Guardrail system me kya-kya screen hota hai?
Prompts aur outputs ko injection, profanity, sensitive data aur policy violations ke liye screen kiya jata hai — aur violations pe block ya redact kiya jata hai. Ye defence-in-depth ki ek layer hai, poora solution nahi.
35Defence-in-depth agentic systems me kaise lagti hai?
Ek layer nahi, kai layers ek saath: input validation, guardrails, least-privilege tools, sandboxing, human approval, logging/monitoring, aur agent ki khud red-teaming. Koi ek layer fail ho to bhi baaki layers pakadti hain.

Digital workers ke roop me — defined tasks sambhalte hain, general intelligence nahi. Value faster decisions aur 24/7 operation me hai. Lekin decision hamesha insaan ke paas rehta hai, aur ROI claims ko apne pilot se verify karna chahiye.
