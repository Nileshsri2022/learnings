Ch 1 — Prompting ke Paanch Siddhant

Prompt engineering ke paanch siddhant — direction, format, examples, evaluation, divide labor — ek loop me, har ek worked example ke saath.

Core idea — paanch siddhant, ek loop

Prompt engineering ke paanch siddhant hain, ek sequence me: Give Direction → Specify Format → Provide Examples → Evaluate Quality → Divide Labor. Inhe ek continuous loop me dobaara visit kiya ja sakta hai, jaise-jaise prompt ko iterate karte ho.

Ye circle wapas Give Direction par aata hai — har iteration me prompt behtar hota hai.

1. Give Direction — direction do

Model ko saaf directions do: kya karna hai, kaunsi role adopt karni hai, task ka end goal kya hai, aur rules kya hain. Ise ek compass ki tarah samjho — ek direction, ek destination ke saath.

Worked example (a) — shoe naming

Pehla prompt: "Give me five potential brand names for a new running shoe" — output generic aur uninspiring tha. Revised prompt: "You are a product manager, develop a brand name for a new running shoe designed for trail runners, the shoe should be lightweight and durable, and the brand name should be short, memorable, and reflect the shoe's key features." Naya output: TrailBlazer, SwiftSole, TerraTrack, PeakRunner, AeroTrail.

Worked example (b) — blog writing

Pehla prompt: "Write a blog post about AI and climate change" — output generic tha, brief par khara nahi utarta tha. Revised prompt: "You are an expert writer, write a 500-word blog post on how AI can help mitigate climate change, focusing on renewable energy, the target audience is tech-savvy readers, use a conversational tone, include a call to action to embrace AI in renewable energy, and include the phrase 'AI can help us solve the climate crisis' in the conclusion." Naya output bahut zyada specific tha aur required phrase conclusion me use hui thi.

General advice: context do, ek role set karo (jaise product manager, lawyer, ya software developer), end goal batao, aur intended output ke terms me socho — agar blog post ka title chahiye to wahi kaho; agar output bullet points ki list honi chahiye to wahi kaho.

2. Specify Format — format tay karo

Jab direction sahi ho lekin response useful format me na ho, to desired output format specify karo: table, bullet points, code, HTML, email, ya koi bhi structured form.

Worked example — blog post idea

Prompt "Write a blog post about the latest trends in AI" se paragraph-form post mili. Revised prompt: "Write a blog post about the latest trends in AI, in the format of an email, with a catchy subject line, a 100-word summary, and a 300-word body." Response email ke format me aayi — required subject line, 100-word summary, aur 300-word body ke saath. Format content ke chaaron taraf ek "shape" hai; agar result intended format me nahi hai, to format specify karo.

3. Provide Examples — examples do (few-shot learning)

Model ko task ke kuch examples do, aur woh unki nakal karega — yehi few-shot learning hai.

Example: model ko "Classify these reviews as positive or negative" kehne par inconsistent labels mile — "I love this product" ko Positive label mila, lekin "I am so happy with this product" ko Neutral label mila. Fix: do example reviews do — ek negative aur ek positive — phir classify karne wala review do, aur model example pattern ko follow karega.

Worked example — product naming

Prompt "Generate names for a new line of running shoes" se generic names mile. Revised prompt: "You are a product manager at a company that makes running shoes; generate names for a new line of running shoes, using the following as examples: 'Zoom X', 'Pegasus', 'Ghost', 'Gel Kayano', 'Fresh Foam', 'Nike React', 'Ultraboost', 'Cloudswift', 'Speedgoat', 'Clifton'." Naya output example style ko follow karta tha — wahi names, wahi style.

Example structure ka rule: Example 1: "I love this product" — Positive; Example 2: "I hate this product" — Negative. Model ko desired output ke examples do, woh unki nakal karega.

4. Evaluate Quality — quality check karo

Evaluate karo ki output requirements par khara utarta hai ya nahi, aur iterate karo — ek explicit evaluation step ke saath.

Kitab ka evaluation workflow: (i) prompt likho aur response lo; (ii) evaluate karo ki response requirements par khara utarta hai ya nahi; (iii) prompt revise karo aur naya response lo; (iv) dobaara evaluate karo.

Model ki "quality" ka bhi istemal hota hai — jaise detailed answer chahiye to GPT-4 use karo, quick simple answer ke liye GPT-3.5 — aur prompt ke alag-alag versions ko compare karo.

Worked example — capital wale sawal

Prompt "What is the capital of France?" — response "Paris". Kitab is illustration me batati hai ki model galat bhi ho sakta hai, aur evaluation se user decide kar sakta hai. Phir: Prompt "What is the capital of Australia?" — response "Canberra" — wahi check. Principle: jawab ko bas accept mat karo; requirements ke against evaluate karo aur iterate karo.

5. Divide Labor — kaam baanto

Ek task ko subtasks me todo aur har ek ko model ya human ko assign karo. Model ko woh subtasks do jinme woh sabse achha hai.

Worked example — blog post

Prompt "Write a blog post about AI and climate change" se generic post mili. Divided prompt: pehle, blog post ka outline generate karo; doosra, introduction likho; teesra, body likho; chautha, conclusion likho. Result: ek post jisme clear outline, introduction, body aur conclusion tha. Wahi principle product-naming par: model se names ki list generate karwao, phir unhe evaluate karwao, phir best wala select karwao.

Model ek collaborator hai, replacement nahi — human ka role use guide karna hai.

A Note About "Human In The Loop"

Human ko loop me rehna hi chahiye: model ek tool hai, human judgement ka replacement nahi. Human ko output ko review, evaluate aur refine karna chahiye, aur final result ki zimmedari leni chahiye. Model hallucinate kar sakta hai, galtiyan kar sakta hai, aur biased output de sakta hai — human ko check karna hi hai.

Summary

Paanch siddhant: Give Direction, Specify Format, Provide Examples, Evaluate Quality, aur Divide Labor. Inhe sequence me use karo aur prompts ko iterate karte hue loop me dobaara visit karo.

Ch 2 — LLMs ka Introduction

LLM agla token predict karke text banata hai — tokens, temperature, top-p, top-k aur GPT-4 ka farak samjho.

Introduction — LLM kya hai

LLM ek aisa model hai jo bade amount me text data par train hua hai aur text generate kar sakta hai. Ye previous words ko dekhkar sequence me agla word (token) predict karke kaam karta hai. Ye ek database nahi hai — ye facts ko "jaanta" nahi hai, ye likely text predict karta hai. Kitab iski analogy deti hai: ek "text autocomplete" jisne bahut zyada text padha hai.

The Basics of Text Generation

Model agla token predict karta hai, phir use apne input me jodkar uske baad wala predict karta hai — isi tarah text banta hai. Isiliye output kabhi-kabhi plausible lekin galat ho sakta hai: model sach nahi bol raha, probability ke hisaab se likely text bana raha hai.

From Text to Tokens

Model process karne se pehle text ko tokens me todta hai. Token text ka ek tukda hai — ek word, word ka hissa, ya punctuation mark.

SentenceTokensCount
"Hello, how are you?"["Hello", ",", " how", " are", " you", "?"]6 tokens

Token counts isliye matter karte hain kyunki models ki context-window limits hoti hain aur pricing per token hoti hai.

Understanding the Key Concepts: Temperature, Top P, Top K, Max Tokens, and More

  • Temperature — randomness / creativity control karta hai. Low temperature (jaise 0.2) zyada deterministic, focused output deta hai; high temperature (jaise 0.9) zyada random, creative output deta hai.
  • Top P (nucleus sampling) — tokens ki cumulative probability mass control karta hai. Jaise top_p=0.9 ka matlab hai sirf un tokens par consider karo jinki cumulative probability 90% hai.
  • Top K — choice ko K sabse likely next tokens tak limit karta hai. Jaise top_k=50.
  • Max tokens — generated output ki length limit karta hai.
  • Frequency penalty — pehle se use hue tokens ki repetition kam karta hai.
  • Presence penalty — model ko naye topics par baat karne ke liye encourage karta hai.
  • Stop sequences — model ko batate hain ki generation kab rokni hai.

GPT-4

Likhne ke samay par GPT-4 ko OpenAI ka sabse advanced model bataya gaya hai — behtar reasoning, bada context, aur multimodal capability (text aur images). Ye GPT-3.5 se zyada mehenga aur slow hai, lekin zyada accurate hai.

Ch 3 — ChatGPT ke Standard Practices

Zero-shot, few-shot, chain of thought, self-consistency, least-to-most — aur structured output, chunking, tokens aur memory.

Introduction — ChatGPT kitna versatile hai

ChatGPT sirf ek chatbot nahi — ye ek versatile tool hai jo likhne, classify karne, translate karne, code karne aur reason karne me istemal ho sakta hai. Is chapter ke saare examples ChatGPT (GPT-4, jab tak kuch aur na kaha jaye) ke saath hain.

Basic Prompt Engineering Techniques in ChatGPT

Chapter 1 ke paanch siddhanton ko ChatGPT par lagana: saaf direction, format, examples, evaluation, aur kaam baantna. Neeche ke techniques unhi siddhanton ke concrete roop hain.

Zero-Shot Prompting

Bina kisi example ke seedha poochho. Example: "Classify the following review as positive, negative, or neutral: 'The product arrived on time and works perfectly.'" → Positive. Aur: "Translate 'Hello, how are you?' into French." → "Bonjour, comment allez-vous?"

Few-Shot Prompting

Pehle examples do, phir naya case do. Example: do labelled reviews (positive / negative), phir teesra review classify karne ko do — model pattern ko follow karta hai.

Chain of Thought Prompting

Model se jawab dene se pehle step by step reason karne ko kaho.

Worked example — bat aur ball

"A bat and a ball cost $1.10 in total. The bat costs $1.00 more than the ball. How much does the ball cost?" — bina CoT ke model $0.10 jawab de sakta hai (galat). "Let's think step by step" ke saath woh is tarah solve karta hai: bat = ball + $1.00; bat + ball = $1.10; to 2 × ball + $1.00 = $1.10; ball = $0.05. Sahi jawab: 5 cents.

Self-Consistency Prompting

Kai CoT reasoning paths sample karo aur majority answer lo. Example: wahi bat-and-ball problem kai baar sample karo; sabse common answer (5 cents) final mana jata hai.

Least-to-Most Prompting

Ek mushkil problem ko aasan sub-problems me todo aur unhe order me solve karo. Example: ek multi-step maths / word problem ko sub-questions me tod do, har ek ka jawab do, phir combine karo.

Structured Output in ChatGPT

Output ko structured format me maango — machine-readable aur parse karne me aasan.

Formatting Output as Lists

Numbered ya bulleted list maango — jaise "List five benefits of exercise".

Formatting Output as Tables

Markdown table maango — jaise AI tools ki table, columns Name / Description / Price ke saath.

Formatting Output as JSON

JSON output maango — jaise ek JSON object, keys "name", "age", "city" ke saath.

Formatting Output as YAML

YAML output maango — configuration ya structured data ke liye.

Formatting Output as XML

XML output maango — jahan tags wali structure chahiye.

Writing Longer Content with Chunking

Model ki token limit hoti hai, isliye lambe document ko chunks me todo, har chunk ko summarise karo, phir chunk summaries ko combine karke final summary banao. Example: ek lamba article 3 chunks me toda gaya, har ek summarise hua, phir teeno summaries combine hui.

Working with ChatGPT Memory

ChatGPT ek session ke andar conversation yaad rakhta hai (short-term memory), lekin sessions ke beech yaad nahi rakhta (likhne ke samay par). Uska ek knowledge cutoff hai aur woh uske baad ki events nahi jaanta. Context window ke baare me kitab samjhati hai: jaise conversation badhti hai, purane messages context se bahar gir jate hain.

How ChatGPT Works Behind the Scenes: An Inside Look at Its Memory and Knowledge

Model ke paas koi live database nahi hai — uski "knowledge" training data me hai, ek cutoff date tak. Session ke andar woh context window me maujood conversation ko use karta hai; window bhar jane par purani baatein gir jati hain.

The Token Limit in ChatGPT

Token limit woh maximum tokens hai jo model ek request me process kar sakta hai (prompt + response). Lambe prompt ka matlab chhota response ke liye jagah — aur iska ulta bhi.

Counting Tokens with Tiktoken

Tiktoken OpenAI ki tokenizer library hai. Kitab isse tokens ginna dikhati hai — aur yaad dilati hai ki 1,000 tokens ≈ 750 words.

Sentiment Analysis with ChatGPT

ChatGPT se text ko positive / negative / neutral classify karwao, examples ke saath. Example reviews upar wale examples jaise hi classify hote hain.

Role Prompting in ChatGPT

Ek role assign karo — jaise "You are a marketing expert", "You are a lawyer", ya "You are a software developer" — aur model us persona ka tone aur knowledge adopt kar leta hai.

Meta-Prompting

Model se prompt likhne / improve karne me madad maango — jaise "Help me write a prompt to generate blog post ideas about AI" — model ek behtar prompt deta hai, jo phir istemal hota hai.

Introduction to LangChain

LangChain Python me LLM applications banane ka ek framework hai — prompt templates, chains, agents, tools aur memory deta hai.

Setting Up LangChain

Install karo: pip install langchain openai aur related packages; phir OPENAI_API_KEY environment variable set karo.

What Is LangChain?

LangChain LLM apps ke liye building blocks deta hai — alag-alag components jo ek saath jodkar poori application banti hai: prompt templates, chains (LCEL), agents, tools, aur memory.

Your First LangChain Prompt

Pehla prompt seedha model ko invoke karta hai — ChatOpenAI(model="gpt-4") banao aur model.invoke("Hello, how are you?") chalao.

What Is a Prompt Template?

Reusable prompts jisme placeholders hote hain (jaise {topic}, {audience}) jo run time par bhare jate hain. Example: template "Write a blog post about {topic} for {audience}", jisme topic="AI" aur audience="beginners" bhara jata hai.

Creating Prompt Templates

ChatPromptTemplate se template banao, placeholders rakho, aur use chain me lagao. Template ek baar banao, kai baar alag-alag values ke saath istemal karo.

Chaining Prompts with LCEL

LCEL (LangChain Expression Language) components ko pipe operator | se chain karta hai — jaise prompt | model | output_parser — ek step ka output agle step ka input banta hai. Example chain: prompt template → ChatOpenAI model → StrOutputParser, chain.invoke({"topic": "AI"}) se chalaya jata hai.

Agents in LangChain

Agent decide karta hai ki kaunsa tool istemal karna hai, ek loop me: thought → action → observation. Example: ek agent jiske paas calculator tool aur search tool hai, aur ek aisa sawal jiske liye dono chahiye — woh har step par sahi tool chunta hai.

Tools in LangChain

Tools woh functions hain jinhe model call kar sakta hai — jaise calculator, web search, Python REPL. Kitab @tool decorator se ek Python function ko tool banane ka tareeka dikhati hai.

Memory in LangChain

ConversationBufferMemory poori conversation history store karta hai; ConversationSummaryMemory summary store karta hai; doosre memory types ek window ya entities store karte hain. Example: ek chatbot jo kai turns ke baad bhi user ka naam yaad rakhta hai.

Building a Chatbot with LangChain

Chatbot banta hai prompt template + model + memory ko jodkar; chatbot context me jawab deta hai, pehle wale turns ko yaad rakhkar.

How to Evaluate the Quality of Your LLM Applications

LangSmith / LangChain evaluators se outputs ko score karo — jaise model ke jawab ko reference answer se compare karo, ya LLM ko judge banao. Chapter me reported worked result: ek evaluation run me 77.5% accuracy (31/40 correct) mili — chapter ne percentage ko 77.5% bataya hai.

Ch 5 — Vector Databases: FAISS aur Pinecone

Introduction to Vector Databases

Vector database embeddings (vectors) store karta hai aur items ko keyword se nahi, similarity se retrieve karta hai.

Why Vector Databases Are Useful

Semantic search, retrieval-augmented generation (RAG), recommendation, aur LLM ko aise private / lambe documents tak access dena jin par woh train nahi hua — ye sab vector databases se hota hai.

How to Set Up a Vector Database

Do raaste: local open-source (FAISS) ya managed cloud (Pinecone). Dono me pehle embeddings banao, phir unhe store karo, phir similarity se query karo.

Working with Embeddings

Embedding ek text ko numbers ki list (vector) me badal deta hai jo meaning capture karta hai; similar texts ke similar vectors hote hain. Similarity cosine similarity (ya Euclidean distance) se measure hoti hai.

Example: "The cat sat on the mat" aur "A feline rested on a rug" ki cosine similarity high hai, chahe words alag hon; "The stock market rose today" ki in dono se similarity low hai.

How to Create a Vector Database with FAISS

FAISS (Facebook AI Similarity Search) ek local, open-source library hai fast similarity search ke liye. Setup: pip install faiss-cpu; OpenAIEmbeddings se embeddings banao; FAISS.from_documents se vector store banao; locally save / load karo; similarity_search se query karo.

How to Use a Vector Database with Pinecone

Pinecone ek managed, cloud vector database hai. Setup: Pinecone account aur API key banao, embedding model ki dimension ke saath index banao (jaise OpenAI text-embedding-ada-002 ke liye 1536), vectors upsert karo, vector se query karo.

How to Create Embeddings

OpenAIEmbeddings().embed_query("text") ek vector deta hai. Har text ka ek vector banta hai; vector ki dimension embedding model par depend karti hai (ada-002 ke liye 1536).

Creating a Vector Store with LangChain

LangChain se ek call me documents se vector store banao — jaise FAISS.from_documents(docs, embeddings) ya Pinecone.from_documents — phir use retriever ke roop me istemal karo.

Semantic Search

Natural language me query karo; store sabse similar documents deta hai. Example: query "How do I reset my password?" se password-reset help article milta hai, chahe usme exact query words na hon.

Metadata Filtering

Results ko metadata fields se filter karo (jaise source, date, category) — jaise sirf woh documents jahan source="manual" ho, ya date ek di gayi date ke baad ki ho.

Working with Long Documents and Chunking Strategies

Lambe documents ko embed karne se pehle chunks me todo, taaki har chunk model ke context me fit ho aur akele retrieve ho sake. Chunking strategies:

  • Fixed-size chunks — jaise 1,000 characters, 200-character overlap ke saath.
  • Recursive splitting — paragraphs / sections ke hisaab se todna.
  • Semantic chunking — matlab ke hisaab se todna.

Example: ek lamba PDF chunks me toda jata hai, har chunk embed hota hai, aur query sirf relevant chunks retrieve karti hai.

Introduction to Diffusion Models

How Diffusion Models Work

The Role of Noise in Diffusion Models

FAQs — Interview Sawal-Jawab

Current-era interviews ke liye 36 sawal-jawab — har chapter se, kitab ke concepts, numbers aur examples par based. Har jawab khud me poora hai.

Q1Prompt engineering kya hai aur iske paanch siddhant kaunse hain?
Prompt engineering model se achha kaam karwane ki skill hai — saaf prompt likhna, output ko evaluate karna, aur iterate karna. Paanch siddhant, sequence me: Give Direction (direction do), Specify Format (format tay karo), Provide Examples (examples do), Evaluate Quality (quality check karo), aur Divide Labor (kaam baanto). Inhe ek loop me dobaara visit karte hain — har iteration me prompt behtar hota hai. Lab 1 me apna prompt score karke dekho.
Q2Give Direction me role dena kyun important hai?
Role model ko context aur perspective deta hai. Example: 'Give me five potential brand names for a new running shoe' se generic names mile; 'You are a product manager, develop a brand name for a new running shoe designed for trail runners, lightweight and durable, short, memorable' se TrailBlazer, SwiftSole, TerraTrack, PeakRunner, AeroTrail mile. Role + end goal + rules — teeno direction ka hissa hain.
Q3Specify Format ka matlab kya hai? Ek example do.
Jab direction sahi ho lekin response useful format me na ho, to format specify karo — table, bullet points, code, HTML, email. Example: 'Write a blog post about the latest trends in AI' se paragraph-form post mili; 'in the format of an email, with a catchy subject line, a 100-word summary, and a 300-word body' se email format me jawab aaya — subject line, 100-word summary aur 300-word body ke saath. Format content ke chaaron taraf ek shape hai.
Q4Few-shot prompting kya hai aur ye kab kaam karta hai?
Model ko task ke kuch examples do, woh unki nakal karega. Example: bina examples ke 'I am so happy with this product' ko Neutral label mila tha, jabki 'I love this product' Positive tha — inconsistent. Do labelled examples (ek positive, ek negative) dene par model pattern follow karne lagta hai. Product naming me bhi wahi: example names (Zoom X, Pegasus, Ghost...) dene par model usi style me names deta hai.
Q5Evaluate Quality ka workflow kya hai?
Chaar steps: (i) prompt likho aur response lo; (ii) evaluate karo ki response requirements par khara utarta hai ya nahi; (iii) prompt revise karo aur naya response lo; (iv) dobaara evaluate karo. Aur model ki quality bhi choose karo — detailed answer ke liye GPT-4, quick simple answer ke liye GPT-3.5 — aur prompt ke alag versions ko compare karo. Jawab ko bas accept mat karo.
Q6Divide Labor kaise kaam karta hai? Blog post wala example samjhao.
Bade kaam ko subtasks me todo aur har ek alag se karwao. Blog post ke liye: pehle outline generate karwao, phir introduction, phir body, phir conclusion — ek saath 'blog post likho' kehne se generic post milti hai, divided prompt se clear structure wali post milti hai. Wahi product naming par: pehle names ki list, phir unhe evaluate karwao, phir best select karwao.
Q7Human in the loop kyun zaroori hai?
Model ek tool hai, human judgement ka replacement nahi. Model hallucinate kar sakta hai, galtiyan kar sakta hai, biased output de sakta hai. Human ko output review, evaluate aur refine karna chahiye aur final result ki zimmedari leni chahiye. Prompt engineering ka matlab model ko boss banana nahi — use collaborator banana hai.
Q8LLM text kaise generate karta hai?
LLM previous words ko dekhkar sequence me agla word (token) predict karta hai — ek-ek token karke. Ye database nahi hai; ye facts ko 'jaanta' nahi, likely text predict karta hai. Kitab ki analogy: ek text autocomplete jisne bahut zyada text padha hai. Isiliye output plausible lekin galat ho sakta hai — model sach nahi bol raha, probability follow kar raha hai.
Q9Token kya hai? 'Hello, how are you?' kitne tokens hai?
Token text ka ek tukda hai — ek word, word ka hissa, ya punctuation mark. 'Hello, how are you?' 6 tokens me tootta hai: ['Hello', ',', ' how', ' are', ' you', '?']. Token counts isliye matter karte hain kyunki models ki context-window limits hoti hain aur pricing per token hoti hai.
Q101,000 tokens kitne words ke barabar hote hain?
Lagbhag 750 words — kitab ka rule of thumb. Isse cost aur limits ka hisaab lagta hai: agar prompt 2,000 tokens ka hai to woh lagbhag 1,500 words ka hai. Tiktoken se exact count milta hai; Lab 2 me estimate karke dekho.
Q11Temperature, Top-P aur Top-K me kya farak hai?
Temperature randomness control karta hai — 0.2 deterministic/focused, 0.9 random/creative. Top-P (nucleus sampling) cumulative probability mass control karta hai — top_p=0.9 ka matlab sirf un tokens ko consider karo jinki cumulative probability 90% hai. Top-K choice ko K sabse likely tokens tak limit karta hai — jaise top_k=50. Max tokens output ki length limit karta hai; frequency penalty repetition kam karta hai; presence penalty naye topics encourage karta hai; stop sequences generation rokte hain.
Q12GPT-4, GPT-3.5 aur open-source models me se kab kaunsa chunna chahiye?
GPT-4: sabse accurate, behtar reasoning, multimodal — lekin mehenga aur slow. GPT-3.5: tez aur sasta — quick, simple answers ke liye. Open-source (Llama, Mistral): locally chalaye ja sakte hain, lekin aam taur par kam capable. Doosre providers (Claude, Gemini): alag strengths. Choice task, cost aur latency par depend karti hai.
Q13Zero-shot aur few-shot prompting me kya farak hai?
Zero-shot: bina kisi example ke seedha poochho — jaise review classify karo ya 'Hello, how are you?' ko French me translate karo ('Bonjour, comment allez-vous?'). Few-shot: pehle examples do, phir naya case do — model pattern follow karta hai. Zero-shot simple tasks ke liye kaafi hai; jahan format ya labeling consistent chahiye, wahan few-shot behtar hai.
Q14Chain of Thought kya hai? Bat-and-ball wala example samjhao.
Model se jawab dene se pehle step by step reason karne ko kaho ('Let's think step by step'). Bat-and-ball: bat + ball = $1.10, bat ball se $1.00 mehenga. Bina CoT ke model $0.10 bolta hai (galat). CoT se: bat = ball + $1.00; 2 × ball + $1.00 = $1.10; ball = $0.05. Sahi jawab 5 cents hai. Lab 4 me dono tareeke chalakar dekho. Self-consistency iska extension hai — kai CoT reasoning paths sample karo aur majority answer lo; bat-and-ball par 5 samples me 4 baar $0.05 aata hai, isliye majority sahi hoti hai.
Q15Least-to-most prompting kya hai?
Mushkil problem ko aasan sub-problems me todo aur unhe order me solve karo. Multi-step maths/word problem ko sub-questions me tod do, har ek ka jawab do, phir combine karo. Ye divide labor ka reasoning wala roop hai — pehle aasan hissa, phir uske jawab se agla hissa.
Q16Structured output kyun maangna chahiye? Kaunse formats hain?
Structured output machine-readable aur parse karne me aasan hota hai. Lists — 'List five benefits of exercise'. Tables — Markdown table, jaise AI tools ki Name/Description/Price wali table. JSON — keys 'name', 'age', 'city' wala object. YAML — configuration ke liye. XML — tags wali structure ke liye. Format specify karna Chapter 1 ke 'Specify Format' siddhant ka hi application hai.
Q17Chunking kya hai aur token limit se iska kya rishta hai?
Model ki token limit hoti hai (prompt + response). Lambe document ko chunks me todo, har chunk ko summarise karo, phir chunk summaries ko combine karke final summary banao. Example: lamba article 3 chunks me toda gaya, har ek summarise hua, phir teeno summaries combine hui. Tiktoken se tokens gin lo — 1,000 tokens ≈ 750 words.
Q18ChatGPT ki memory kaise kaam karti hai?
ChatGPT ek session ke andar conversation yaad rakhta hai (short-term memory), lekin sessions ke beech yaad nahi rakhta — likhne ke samay par. Uska ek knowledge cutoff hai, uske baad ki events nahi jaanta. Context window bhar jane par purane messages context se bahar gir jate hain — isiliye lambi conversation me purani baatein bhool jata hai.
Q19Role prompting aur meta-prompting kya hain?
Role prompting: ek role assign karo — 'You are a marketing expert' / 'You are a lawyer' / 'You are a software developer' — model us persona ka tone aur knowledge adopt kar leta hai. Meta-prompting: model se prompt likhne/improve karne me madad maango — jaise 'Help me write a prompt to generate blog post ideas about AI' — model behtar prompt deta hai, jo phir istemal hota hai.
Q20LangChain kya hai aur iske components kaunse hain?
LangChain Python me LLM applications banane ka framework hai. Paanch building blocks: prompt templates (reusable prompts, {placeholders} ke saath), chains/LCEL (components ko pipe se jodna), agents (tool chunne ka loop), tools (calculator, search, Python REPL), aur memory (conversation history). Setup: pip install langchain openai, aur OPENAI_API_KEY set karo.
Q21LCEL kya hai? Ek example do.
LCEL (LangChain Expression Language) components ko pipe operator | se chain karta hai — prompt | model | output_parser. Example: ChatPromptTemplate ('Write a blog post about {topic} for {audience}') → ChatOpenAI (gpt-4) → StrOutputParser, chain.invoke({'topic': 'AI', 'audience': 'beginners'}) se chalao. Ek step ka output agle step ka input banta hai. Lab 5 me chain banakar dekho.
Q22LangChain me agent kaise kaam karta hai?
Agent ek loop me kaam karta hai: thought → action → observation. Model decide karta hai ki kaunsa tool istemal karna hai, tool chalata hai, result dekhta hai, phir dobaara sochta hai — jab tak final answer na mil jaye. Example: calculator + search tool wala agent, dono chahiye wale sawal par har step par sahi tool chunta hai. Tools @tool decorator se Python functions se bante hain.
Q23LangChain me memory ke kaunse types hain?
ConversationBufferMemory poori conversation history store karta hai; ConversationSummaryMemory summary store karta hai; doosre types ek window ya entities store karte hain. Example: chatbot jo kai turns ke baad bhi user ka naam yaad rakhta hai. Long-term memory ke liye vector store (Chroma) istemal hota hai — purani interactions similarity se retrieve hoti hain.
Q24LangChain applications ko evaluate kaise karte hain? 77.5% ka kya matlab hai?
LangSmith / LangChain evaluators se outputs ko score karo — model ke jawab ko reference answer se compare karo, ya LLM ko judge banao. Chapter ka worked result: ek evaluation run me 77.5% accuracy mili — 31/40 correct. Matlab: 40 test cases me se 31 sahi jawab mile. Ye number batata hai ki system kitna reliable hai — aur kahan sudhaar chahiye.
Q25Embeddings aur vector database kya hai?
Embedding text ko numbers ki list (vector) me badal deta hai jo meaning capture karta hai; similar texts ke similar vectors hote hain. Similarity cosine similarity (ya Euclidean distance) se measure hoti hai. Example: 'The cat sat on the mat' aur 'A feline rested on a rug' ki similarity high hai, chahe words alag hon; 'The stock market rose today' ki in dono se similarity low hai. Vector database in vectors ko store karke similarity se retrieve karta hai.
Q26FAISS aur Pinecone me kya farak hai? 1536 ka kya matlab hai?
FAISS (Facebook AI Similarity Search) local, open-source library hai — pip install faiss-cpu, FAISS.from_documents se store banao, locally save/load karo. Pinecone managed cloud database hai — account + API key, index banao, vectors upsert karo. 1536 OpenAI text-embedding-ada-002 ki dimension hai — Pinecone index ki dimension embedding model se match honi chahiye.
Q27Semantic search keyword search se alag kaise hai?
Keyword search exact words dhoondta hai; semantic search matlab dhoondta hai. Example: query 'How do I reset my password?' se password-reset help article milta hai, chahe usme exact query words na hon. Lab 6 me sawal likhkar dekho — synonym map se 'password' ka matlab 'credentials' se bhi match hota hai.
Q28Metadata filtering aur chunking strategies kya hain?
Metadata filtering: results ko source, date, category jaise fields se filter karo — jaise sirf source='manual' wale documents. Chunking: lambe documents ko embed karne se pehle chunks me todo — fixed-size (1,000 characters, 200-character overlap), recursive splitting (paragraphs/sections ke hisaab se), ya semantic chunking. Har chunk akele retrieve ho sakta hai.
Q29Autonomous agent kya hai aur ReAct kaise kaam karta hai?
Autonomous agent woh LLM hai jo plan karta hai, tools istemal karta hai, aur har step par human ke bina act karta hai — ek loop me. ReAct (Reason + Act) reasoning traces ko tool actions ke saath interleave karta hai: Thought, Action, Action Input, Observation — Final Answer tak repeat. Example: search + calculation wala sawal, search aur reasoning ko alternate karke solve hota hai.
Q30Function calling kaise kaam karta hai?
Model ko function definitions do (name, description, parameters as JSON Schema) aur woh free text ke bajay ek structured function call deta hai; code function execute karta hai aur result model ko wapas deta hai. Example: get_weather function, location parameter ke saath; model use {'location': 'London'} ke saath call karta hai, code weather deta hai, model use report karta hai.
Q31BabyAGI kya hai?
Ek basic autonomous agent jo tasks banata hai, unhe prioritise karta hai, aur ek loop me execute karta hai — task creation → prioritisation → execution — memory ke liye ek vector store (Chroma) istemal karke. Example: objective 'Plan a marketing campaign' par BabyAGI sub-tasks generate karta hai, unhe prioritise karta hai, aur ek-ek karke kaam karta hai.
Q32Tree of Thoughts kya hai? 4% vs 74% ka kya matlab hai?
ToT me kai reasoning branches ko tree ki tarah explore karo, har branch ko evaluate karo, best ko rakho, aur backtrack karo. Game of 24 (4 numbers se 24 banana) par standard prompting se GPT-4 sirf 4% baar succeed hua, jabki Tree of Thoughts se 74% baar — wahi model, sirf reasoning ka tareeka badla. Ye chapter ka headline comparison hai.
Q33Diffusion models kaise kaam karte hain?
Forward process: clear image me dheere-dheere noise add hota hai jab tak woh pure noise na ban jaye. Reverse process: model step by step noise hatana seekhta hai — pure noise se shuru karke clear image banata hai. Noise starting material hai, kharabi nahi. Text prompt CLIP se encode hokar denoising ko condition karta hai — jaise 'a red sports car' red, car-shaped, sporty features ki taraf steer karta hai.
Q34Midjourney prompt ka format kya hai?
/imagine prompt: [subject], [style], [details] --[parameters]. Pehle subject, phir style/medium, phir lighting/composition, phir parameters jaise --ar (aspect ratio) aur --v (version). Weights :: se — 'cat::2 dog::1' me cat dog se do guna important hai. --no se unwanted cheezein hatao (jaise --no text, --no blurry). /describe se image se prompts reverse-engineer karo; --seed aur --cref se character consistent rakho; /shorten se prompt trim karo.
Q35Stable Diffusion me CFG scale aur steps kya hain? ControlNet, LoRA aur DreamBooth me farak?
Steps denoising steps ki sankhya hai (jaise 20–50); CFG scale batata hai ki prompt ko kitni strongly follow karna hai (jaise 7–8). ControlNet spatial control deta hai — depth map, edge map (Canny), pose skeleton (OpenPose) se structure follow karwata hai. LoRA ek chhota adapter (kuch MB) hai jo style/subject sikhata hai, weight jaise 0.8 par apply hota hai. DreamBooth 3–5 photos par fine-tune karke ek khaas subject sikhata hai, unique token (jaise 'sks dog') ke saath.
Q36AI-powered blog-writing application ke saat steps kaunse hain?
Step 1: SERP research (Serper API se top 10 results). Step 2: Expert interview (LLM ko expert banakar sawal-jawab). Step 3: Outline (research + interview se headings + points). Step 4: Draft (Chroma retriever + LCEL chain se section-by-section). Step 5: Style rewrite (embedding distance se lekhak ki style match karo). Step 6: Images (Stable Diffusion/Midjourney, 'Corporate Memphis' house style). Step 7: Titles (10 titles generate karo, score karo, best chuno). Ant me Gradio UI — demo.launch().
