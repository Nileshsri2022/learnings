Chapter 1 — The Machine Learning Landscape

Machine Learning kya hai, kab istemal karna chahiye, aur kaunse types hote hain — ye chapter poori book ki neev hai. Spam filter ke example se lekar overfitting tak, yahan har concept ki pehchan hogi.

01.1 What Is Machine Learning?

Machine Learning ek aisa program hai jo data se seekhta hai, fixed rules se explicitly program kiye bina. Matlab: rules likhne ke bajaye, computer examples se patterns seekhta hai aur unse predictions ya decisions karta hai.

Classic example spam filter hai. Traditional tareeka: programmer haath se rules likhe — 'agar subject me ye word hai to spam'. ML tareeka: filter ko spam aur non-spam ke examples dikhao, wo khud seekh le ki kaunsa pattern spam hai.

Farak saaf hai: traditional program me rules pehle se likhe hote hain; ML system me rules data se niklte hain. Isi liye ML wahan jeet-ta hai jahan rules likhna mushkil ya impossible hai.

01.2 Why Use Machine Learning?

ML tab istemal karo jab: problem rules se solve karna bahut complex ho; problem ko naye data ke saath adapt karna ho (spam adapt karta rehta hai, isliye fixed rules fail hote hain); complex problems aur bade data se insight chahiye ho.

Examples: spam filtering, speech recognition, product recommendations, image classification, forecasting — har jagah wahi pattern hai: data bahut hai, rules likhna mushkil hai.

Ek aur badi wajah: ML insaanon ko seekhne me madad karta hai. Model train karke use analyse karo, to data ke baare me aisi baatein pata chalti hain jo seedha dekhne se nahi chalti.

01.3 Types of Machine Learning Systems — By Supervision

Sabse pehla classification hai training supervision ke hisaab se — matlab training data me labels hain ya nahi:

  • Supervised learning — labelled training data. Kaam: classification (spam ya nahi) aur regression (keemat kitni hogi). Example: spam classification, price prediction.
  • Unsupervised learning — unlabelled data. Kaam: clustering (similar cheezein ek group me), visualisation, dimensionality reduction, association-rule learning. Example: customer segmentation, anomaly detection.
  • Semisupervised learning — thode labelled + bahut saare unlabelled examples. Example: kuch labelled photos se baaki ko bhi seekh lena.
  • Reinforcement learning — ek agent environment ko observe karta hai, actions leta hai, rewards ya penalties milte hain, aur ek policy seekhta hai. Example: game khelna, robot control.

Interview me sabse zyada poochha jaane wala sawaal yahi hai: 'supervised aur unsupervised me farak kya hai?' — jawaab ek line me: labels hain ya nahi.

01.4 Batch and Online Learning

Doosra classification hai kab train karte ho — ek baar ya lagatar:

  • Batch / offline learning — saare available data par train karo, phir deploy karo; naya data aane par dobara train karna padta hai.
  • Online / incremental learning — data ke stream se on the fly seekho; fast-changing data ke liye achha hai. Risk: kharab data aate hi model kharab ho sakta hai.

Out-of-core algorithm wo hota hai jo data ko chhote chunks me padhta hai, kyunki poora data memory me nahi aata. Agar data RAM se bada hai, to out-of-core hi raasta hai.

Online learning ka risk production me bahut matter karta hai — isliye live system me data quality ko monitor karna zaroori hai (Chapter 2 me detail me).

01.5 Instance-Based versus Model-Based Learning

Teesra classification hai kaise generalise karte ho:

  • Instance-based learning — training examples ko yaad rakho, aur naye example ki prediction similarity se karo. Example: k-nearest neighbours — naye point ke sabse kareeb ke k neighbours dekho, unka majority vote lo.
  • Model-based learning — data se ek model banao (jaise ek line ya equation), aur prediction us model se karo. Training ke baad data ki zaroorat nahi — model hi kaafi hai.

Model-based learning me steps hote hain: model select karo, phir train karo — matlab model ke parameters ko data se fit karo.

01.6 Main Challenges of Machine Learning

ML me sabse badi mushkilein ye hain:

  • Insufficient quantity of training data — data kam ho to model seekh hi nahi payega.
  • Nonrepresentative data — biased ya sampling ki galti se data poori duniya ko represent hi na kare.
  • Poor-quality data — noise, outliers, missing values.
  • Irrelevant features — kaam ke features ke beech bekaar features.
  • Overfitting — model training data ko bahut achhe se fit kar leta hai, noise samet, aur naye data par kharab perform karta hai. Ye book ka central failure mode hai.
  • Underfitting — model bahut simple hai, pattern hi nahi pakad raha.

Is curve ko samajh lo: training error hamesha girti hai complexity badhane se, lekin test error U-shape banati hai — pehle girti hai, phir overfitting threshold ke baad badhne lagti hai. Best model wahi hai jahan test error sabse kam ho. Isi balance ko regularisation se control karte hain.

Regularisation ka matlab hai model ko thoda 'rokna' — taaki wo training data ko rat na le.

01.7 Testing and Validating

Model ko test karne ke tareeke:

  • Train/test split — data ko do hisso me baanto: train par seekho, test par check karo.
  • Generalisation error — naye, unseen data par error kitni hogi, yehi asli performance hai.
  • Holdout validation — ek hissa alag rakh kar validation karo.
  • Cross-validation (k-fold) — data ko k folds me baanto, har fold ko ek baar test banao, baaki par train karo — zyada reliable estimate milta hai.

No free lunch — koi ek model har problem ke liye best nahi hota. Har problem ke liye alag model try karna padta hai, aur cross-validation se compare karna padta hai.

Chapter 2 — End-to-End Machine Learning Project

Ye chapter poori book ki neev hai — ek real project, California ke ghar ke daam predict karna, shuru se ant tak. Data lana, explore karna, prepare karna, model train karna, tune karna, aur deploy karna — sab kuch isi ek project me seekhoge.

02.1 Framing the Problem — Business Objective

Running project hai California median house values predict karna (1990 census data). Pehla kaam hai business objective define karna: ek district ki median house value predict karni hai.

Performance measure hai RMSE — root mean squared error — aur book ke example framing me tolerance lagbhag $5,000 rakhi gayi hai. RMSE ke bajaye MAE (mean absolute error) bhi ho sakta tha, lekin RMSE bade errors ko zyada penalise karta hai, isliye chuna gaya.

Framing ke steps: objective define karo, performance measure chuno, assumptions list karo, aur data sources ki list banao. Ye steps skip karne se project baad me bhatakta hai.

RMSE dollar me hota hai — isliye iska matlab seedha samajh aata hai: RMSE $50,000 matlab predictions aam taur par $50,000 aas-paas galat hain.

04.1 Linear Regression aur Normal Equation

04.2 Gradient Descent

Gradient Descent cost function ko step by step neeche le jata hai — har step me gradient ke opposite direction me chhota kadam. Learning rate η kadam ka size decide karta hai.

  • Batch GD — har step me poora dataset istemal karo. Stable, lekin bada data par slow.
  • Stochastic GD — har step me ek instance. Noisy hai, lekin local minima se nikal sakta hai; learning-rate schedule chahiye hota hai.
  • Mini-batch GD — chhote batches (jaise 32/64). Dono ka beech ka raasta — aaj kal sabse zyada istemal hota hai.

Learning-rate ki galtiyan (Figure 4-3/4-4): bahut chhota rate = bahut slow; bahut bada rate = diverge — cost badhne lagti hai, model explode ho jata hai. Feature scaling GD ke liye bahut zaroori hai (Figure 4-2, contour plots) — bina scaling ke GD zig-zag karta hai aur slow hota hai.

Chapter 5 — Support Vector Machines

Support Vector Machines — large margin ka idea, kernel trick, aur SVM regression. Ye chapter batata hai ki ek simple idea (classes ke beech sabse chaudi 'street') kitni powerful ho sakti hai.

05.1 Linear SVM Classification — Large Margin

Linear SVM ka idea hai large margin — classes ke beech sabse chaudi 'street' banao. Street ke edge par jo instances hote hain, unhe support vectors kehte hain — wahi decision boundary ko decide karte hain.

Hard margin sirf separable data ke liye hai — aur outliers se bahut sensitive hai. Soft margin violations allow karta hai, jise C control karta hai: chhota C = chaudi street, zyada violations; bada C = patli street, kam violations.

Iris dataset (petal length/width) par LinearSVC(C=1) lagbhag 96% accuracy deta hai; C=0.01 par street chaudi hoti hai aur accuracy thodi gir jati hai.

05.2 Nonlinear SVM — Polynomial Kernel

Data linearly separable na ho to polynomial features add karo — ya kernel trick istemal karo. Do tareeke: PolynomialFeatures + LinearSVC, ya seedha SVC(kernel="poly", degree=3, coef0=1, C=5).

Book ke moons example me: PolynomialFeatures(degree=3) + LinearSVC(C=5) se decision boundary moons ko follow karti hai; SVC(kernel="poly", degree=3, C=5) se bhi similar result milta hai.

05.3 Gaussian RBF Kernel

Gaussian RBF kernel (SVC(kernel="rbf", gamma=0.1, C=0.001)) har training instance ke aas-paas ek 'influence' banata hai. Gamma us influence ka radius control karta hai: chhota gamma = chauda, smooth boundary; bada gamma = patla, tedha-medha boundary.

Moons par gamma=0.1, C=0.001 se achhi separation milti hai, jabki gamma=5 overfit karta hai — boundary training points ke aas-paas ghumne lagti hai.

Python

SVC(kernel='rbf', gamma=5, C=0.001)     # overfit — boundary tedhi-medhi

05.4 SVM Regression (SVR)

SVR (Support Vector Regression) me ε-insensitive tube hoti hai — tube ke andar ki errors (|error| ≤ ε) ignore ki jati hain. C trade-off control karta hai.

Book generated data par SVR(kernel="poly", degree=2, C=100, epsilon=0.1) istemal karta hai aur test RMSE lagbhag 0.5–0.6 report karta hai (LinearRegression ka lagbhag 0.7 tha). RBF kernel aur scaled features se RMSE aur kam hota hai.

05.5 Under the Hood — Decision Function aur Kernel Trick

Decision function hai wᵀx + b. SVM ke peeche do formulations hain: primal aur dual problem. Kernel trick ka matlab hai: high-dimensional space me dot products compute karo, bina explicitly map kiye — isse dual problem me kernel function K(xᵢ, xⱼ) dot product ki jagah le leta hai (detail Appendix C me).

Book ki warning: SVM powerful lekin slow hai bade datasets par — complexity O(n²) – O(n³) — aur feature scaling zaroori hai.

06.4 The CART Training Algorithm

CART greedy tareeke se train karta hai — recursive splitting: har node par wo split chuno jo impurity ko sabse zyada kam kare.

Impurity ke do measures:

  • Gini impurity G = 1 − Σ pᵢ² — pure node ke liye 0, binary balanced ke liye max 0.5.
  • Entropy H = −Σ pᵢ log₂ pᵢ — pure node ke liye 0, binary balanced ke liye max 1.

Book batata hai ki Gini thoda faster hai (log compute nahi karna padta) aur Scikit-Learn me default hai. Dono ke results aam taur par similar hote hain.

06.5 Computational Complexity

CART training ki complexity lagbhag O(n × m × log n) hoti hai — n instances, m features. Prediction fast hai — tree ki depth ke proportional, lagbhag O(log n).

Matlab: train karna mehenga ho sakta hai, lekin predict karna sasta hai — production me yehi matter karta hai.

06.6 Gini Impurity or Entropy?

Dono me se kaunsa chune? Book ka jawab: zyada farak nahi padta — dono similar trees banate hain. Gini thoda faster hai, isliye default hai.

Entropy kabhi-kabhi thodi zyada balanced trees banati hai, lekin difference chhota hota hai. Interview me ye sawaal poochha jata hai — jawab: 'Gini default hai kyunki faster hai, results similar hote hain.'

  • max_depth — tree kitna gehra ho sakta hai.
  • min_samples_split — node split karne ke liye kam se kam kitne samples chahiye.
  • min_samples_leaf — har leaf me kam se kam kitne samples hone chahiye.
  • min_weight_fraction_leaf — leaf ka minimum weight fraction.
  • max_leaf_nodes — zyada se zyada kitne leaves.
  • max_features — har split par kitne features consider karo.

Chapter 7 — Ensemble Learning and Random Forests

Ek model se behtar hai kai models ka group — ensemble. Voting, bagging, Random Forests, boosting, stacking: har technique ek hi idea par hai — kai kamzor learners ko jod kar ek mazboot learner banao.

07.1 Voting Classifiers

Voting classifier me kai classifiers ki predictions ko jodte hain. Hard voting — majority class jeetti hai. Soft voting — predicted probabilities ka average lete hain; ye aam taur par behtar hota hai, agar classifiers well-calibrated hon.

Book ka example moons par: LogisticRegression, RandomForestClassifier, SVC (probability=True) — individual accuracies lagbhag 84–88%, voting classifier lagbhag 89–90% (soft voting hard se thoda behtar).

07.2 Bagging and Pasting

Bagging (bootstrap aggregating): kai predictors ko data ke random subsets (with replacement) par train karo, phir aggregate karo. Pasting wahi hai, bina replacement ke. Dono variance kam karte hain.

Out-of-bag (OOB) evaluation: har bootstrap sample me lagbhag 37% instances chhoot jate hain — in par evaluate karo, to test performance ka estimate mil jata hai bina alag validation set ke. Book ka BaggingClassifier (DecisionTree, 500 trees) moons par lagbhag 90% accuracy deta hai, OOB bhi lagbhag 90%.

07.3 Random Patches and Random Subspaces

Random patches: instances ke saath-saath features ke bhi random subsets lo. Random subspaces: sirf features ke random subsets lo, saare instances rakho.

Ye techniques trees ko aur diverse banati hain — aur diversity hi ensemble ki taakat hai. Agar saare trees ek jaise honge, to ensemble ka koi fayda nahi.

07.4 Random Forests

Random Forests = bagging of trees + har split par random feature subsets (max_features). Book ka RandomForestClassifier (500 trees) moons par lagbhag 92% accuracy deta hai.

Feature importances: Random Forest batata hai ki kaunsa feature kitna kaam ka hai — Iris par petal length/width dominate karte hain. Extra-Trees (Extremely Randomised Trees) random thresholds istemal karte hain — faster hote hain, aksar similar accuracy, thoda zyada bias.

07.5 Boosting — AdaBoost aur Gradient Boosting

Boosting me predictors sequentially train hote hain — har naya predictor apne predecessors ki galtiyan sudharta hai.

  • AdaBoost — AdaBoostClassifier with DecisionTreeClassifier(max_depth=1) stumps, 200 estimators, learning_rate=0.5. Book ke moons par accuracy lagbhag 92–93%.
  • Gradient Boosting — har naya tree previous ensemble ke residual errors ko fit karta hai. Book ka example quadratic data par: 3 trees (depth 2, learning_rate=0.1) se RMSE lagbhag 0.8 se 0.3 tak sudharta hai. Early stopping bhi hai — staged_predict se behtar point par rok do.

XGBoost ek fast, popular gradient-boosting library hai (Scikit-Learn me nahi hai) — production me bahut istemal hoti hai.

07.6 Stacking (Blending)

Stacking me ek meta-learner (blender) ko diverse base predictors ki out-of-fold predictions par train karte hain. Book ka example moons par RandomForest, ExtraTrees, GradientBoosting aur MLP ko stack karta hai aur lagbhag 92–93% accuracy pata hai — best single model se thoda behtar.

Stacking ka rule: base models diverse hone chahiye — ek jaise models stack karne ka fayda nahi.

Chapter 8 — Dimensionality Reduction

Zyada features hamesha achhe nahi hote — kabhi-kabhi wo shor hote hain. Dimensionality reduction data ko chhota karta hai, bina uski jaan khoye. PCA se lekar t-SNE tak, yahan har badi technique hai.

08.1 The Curse of Dimensionality

Curse of dimensionality: high dimensions me data sparse ho jata hai, distances ka matlab kam ho jata hai, aur training instances ki zaroorat exponentially badhti hai.

Book ka illustration: 1-D, 2-D, 3-D space me points — aur hypercube ka volume. Dimensions badhane par data itna phail jata hai ki har point akele pad jata hai — isliye zyada dimensions me model ko bahut zyada data chahiye hota hai.

08.2 Main Approaches — Projection vs Manifold Learning

Do bade approaches hain:

  • Projection — data ek lower-dimensional subspace ke paas pada hai — us par project kar do. Example: PCA.
  • Manifold learning — data ek twisted low-dimensional manifold par pada hai — use unfold karo. Example: Swiss roll.

08.3 PCA — Principal Component Analysis

Book ka MNIST PCA example: 784 → 154 components par 95% variance retain hoti hai. Reconstruction error kam hoti hai — 154 components se banayi gayi MNIST images pehchanne layak dikhti hain.

PCA ke istemal: compression (MNIST images 154 components se reconstruct karo), visualisation (2-D/3-D scatter, Figure 8-5), aur preprocessing step (PCA(n_components=0.95)). Incremental PCA (IPCA) bade datasets ke liye hai; randomised PCA (svd_solver="randomized") speed ke liye hai.

10.1 From Biological to Artificial Neurons

Biological neuron me dendrites signals lete hain, axon signal bhejta hai, aur synapses connection hote hain. Artificial neuron wahi idea hai: weighted sum + activation function.

Perceptron (single TLU, step function, 1957 me pehla version) sirf linearly separable problems solve kar sakta tha — early researchers ne dikhaya tha ki single-layer perceptron XOR jaisi simple problem bhi nahi solve kar sakta. MLP (Multi-Layer Perceptron) — ek ya zyada hidden layers — XOR solve kar sakta hai aur principle me kisi bhi continuous function ko approximate kar sakta hai.

10.2 Activation Functions

Activation functions decide karti hain ki neuron kab 'fire' kare:

  • Step — 0 ya 1, perceptron me istemal hoti thi.
  • Sigmoid (logistic) — 0–1 ke beech, saturate ho jati hai (bade inputs par gradient lagbhag 0).
  • Tanh — −1 se +1, zero-centred — sigmoid se thoda behtar.
  • ReLU (max(0, z)) — hidden layers ka default: fast hai, positive inputs par saturate nahi hoti, lekin 'die' kar sakti hai (hamesha 0 output).
  • Leaky ReLU / ELU / SELU — ReLU ke variants jo dying ReLU se bachate hain.

10.3 Training MLPs with Backpropagation

Backpropagation ke steps: forward pass (input se output tak compute karo), loss compute karo, phir backward pass (reverse-mode autodiff, chain rule) se har weight ke liye gradient nikalo, aur gradient descent se weights update karo.

Book ek chhote two-layer example se samjhata hai (Figure 10-6/10-7) — forward me values compute karo, backward me gradients. Yehi backprop hai — deep learning ki engine.

Chapter 11 — Training Deep Neural Networks

Deep networks train karna mushkil kyun hai — vanishing gradients, slow optimisers, overfitting — aur in sabke fixes: batch normalisation, behtar initialisation, Adam, dropout, aur learning-rate schedules.

11.1 Vanishing / Exploding Gradients Problems

Deep nets me gradients shrink (vanish) ya exponentially grow (explode) ho sakte hain. Sigmoid/tanh saturate hote hain, aur kai layers se guzarne par gradient lagbhag 0 ho jata hai — neeche wali layers train hi nahi hoti.

Symptoms: lower layers ke weights barely badalte hain, training bahut slow hoti hai. Fixes: behtar initialisation, non-saturating activations (ReLU family), batch normalisation, gradient clipping.

11.2 Initialisation — Fan-Average aur ReLU-Friendly

Weights ki initialisation bahut matter karti hai:

  • Fan-average initialisation — variance 1/fan_avg (fan_in aur fan_out ka average). Sigmoid/tanh ke liye achha hai.
  • ReLU-friendly initialisation — variance 2/fan_in. ReLU ke liye banayi gayi hai — kyunki ReLU aadhe inputs ko zero kar deta hai, isliye variance double chahiye hoti hai.

Galat initialisation se training shuru hi nahi hoti — ya to gradients vanish karte hain, ya explode karte hain. Sahi initialisation se deep net seedha train hone lagta hai.

11.3 Batch Normalisation

Batch Normalisation har layer ke inputs ko normalise karta hai — zero mean, unit variance per mini-batch — phir learnable γ (scale) aur β (shift) se adjust karta hai. Book ise activation se pehle lagata hai.

Book ka Fashion MNIST model BN ke saath lagbhag 89–90% accuracy pata hai, aur faster convergence hoti hai (Figure 11-3/11-4). BN regulariser ki tarah bhi kaam karta hai — overfitting kam hota hai.

Python
keras.layers.BatchNormalization()  # activation se pehle lagao

11.4 Gradient Clipping

Gradient clipping exploding gradients se bachata hai — gradients ko value ya norm se clip karo (jaise clipnorm=1.0). RNNs ke liye khaas taur par zaroori hai (Chapter 15).

11.5 Reusing Pretrained Layers — Transfer Learning

Transfer learning: kisi similar task par train hue model ki lower layers reuse karo — unhe freeze karo, sirf top layers train karo, phir optionally unfreeze karke low learning rate se fine-tune karo.

Unsupervised pretraining (pehle bina labels ke train karo, phir fine-tune karo) ab kam istemal hoti hai — lekin concept samajhna zaroori hai. Pretraining on auxiliary tasks bhi ek tareeka hai — related task par train karo, phir asli task par aao.

Transfer learning ka fayda: kam data par bhi achha model — kyunki lower layers ne pehle se hi general features seekh liye hote hain (edges, shapes, patterns).

11.6 Faster Optimizers — Momentum se Adam Tak

Optimisers ki kahani:

  • Momentum — velocity accumulate karta hai, plateaus aur ravines ko paar karne me madad karta hai.
  • Look-ahead momentum (NAG) — aage dekh kar gradient compute karo — momentum se behtar.
  • AdaGrad — har parameter ke liye learning rate adapt karo, lekin time ke saath decay hoti hai.
  • RMSProp — AdaGrad with exponential decay — decay ki problem solve karta hai.
  • Adam — momentum + RMSProp, bias correction ke saath. Book ki default recommendation hai (lr=0.001). Adamax/Nadam iske variants hain.

Book Fashion MNIST par optimisers ko compare karta hai (Figure 11-5/11-6): Adam sabse fast converge karta hai.

Python

keras.optimizers.SGD(lr=0.01, momentum=0.9, nesterov=True)

11.7 Learning Rate Scheduling

Learning rate ko training ke dauran badalna — scheduling:

  • Constant — ek hi rate poori training.
  • Exponential decay — rate dheere-dheere kam karo. Book ka example: initial lr 0.01, decay_steps 10,000, decay_rate 0.9.
  • Piecewise constant — kuch epochs ke baad rate ko step se kam karo.
  • Performance scheduling (ReduceLROnPlateau) — validation loss ruk jaye to rate kam karo.
  • 1-cycle / cyclical learning rates — rate ko upar-neeche le jao.
Python
ExponentialDecay(initial_learning_rate=0.01,
                 decay_steps=10000, decay_rate=0.9)

11.8 Avoiding Overfitting — Regularization aur Practical Guidelines

Overfitting se bachne ke tareeke:

  • L1/L2 weight regularisation — kernel_regularizer="l2" se weights ko bada hone se roko.
  • Dropout — training ke dauran randomly units ko drop karo (rate 0.2–0.5). Test time par keep probability se scale karo (inverted dropout). Book ka Fashion MNIST model dropout 0.2 ke saath lagbhag 88–89% pata hai aur kam overfit karta hai.
  • Max-norm regularisation — weights ko max norm tak clip karo (jaise max_norm(2.0)).
  • Early stopping — EarlyStopping(patience=10, restore_best_weights=True) se best weights par wapas aao.
  • Data augmentation — images ke liye (Chapter 14 me detail me).

Book ka practical guidelines checklist (Table 11-1): simple se shuru karo, ReLU-friendly initialisation + ELU/ReLU + BN istemal karo, Adam optimizer, dropout, aur recommended defaults ka table. Ye checklist apne har deep-learning project me istemal karo.

Ek aur prerna: pehle computer vision models (jaise Neocognitron) se bhi CNNs ne seekha — lekin CNNs ne supervised backprop se training ko practical banaya.

14.2 Convolutional Layers

Convolutional layer filters (kernels) ko image par slide karta hai aur feature maps banata hai. Har filter ek feature dhoondhta hai (edge, texture). Parameters: filters ki sankhya, kernel size, stride, padding ('same' ya 'valid'), dilation.

Fayda: parameter sharing — ek filter poori image par istemal hota hai, isliye parameters bahut kam hote hain Dense layer se.

14.3 Pooling Layers

Pooling layers feature maps ko chhota karte hain:

  • Max pooling — har window ka sabse bada value lo — sabse zyada istemal hota hai.
  • Average pooling — har window ka average lo.
  • Global average pooling — poori feature map ka average — classifier head me istemal hota hai.

Pooling se translation invariance milti hai (thoda sa shift hone par bhi wahi result) aur computation kam hota hai.

14.4 CNN Architectures — LeNet-5 se Xception Tak

  • LeNet-5 (1998) — pehla successful CNN, digit recognition ke liye.
  • AlexNet (2012) — ImageNet jeeta, deep learning ki wapasi ki shuruaat.
  • GoogLeNet (2014) — Inception modules, bahut gehra lekin efficient.
  • VGG (2014) — simple: sirf 3×3 convolutions, lekin bahut gehra.
  • ResNet (2015) — skip connections — bahut gehri nets train karna possible hua.
  • Xception (2016) — depthwise separable convolutions.
  • SENet (2017) — squeeze-and-excitation blocks.

Chapter 15 — Processing Sequences Using RNNs and CNNs

Chapter 16 — Natural Language Processing with RNNs and Attention

16.1 Generating Text — Character RNN

Chapter 17 — Autoencoders, GANs, and Deep Generative Models

Naya data banana — images, text, music. Autoencoders se compression, VAEs se sampling, aur GANs se woh images jo asli lagti hain.

17.1 Efficient Data Representations — PCA se Autoencoders Tak

Data ko chhoti representation me badalna — PCA (linear) se lekar autoencoders (nonlinear) tak. Autoencoder: encoder input ko latent code me badalta hai, decoder usse wapas reconstruct karta hai.

Book Fashion MNIST par stacked autoencoder banata hai: 784 → 100 → 30 → 100 → 784 — beech me sirf 30 numbers me poori image ki information hoti hai.

17.2 Stacked Autoencoders aur Fashion MNIST

Book stacked autoencoder ko Fashion MNIST par train karta hai — 784 → 100 → 30 → 100 → 784 architecture. Reconstruction achhi hoti hai, aur latent code me images ki meaningful structure hoti hai.

Stacked autoencoders ko greedy layer-wise train kiya jata hai — pehle ek layer, phir agli — phir poori network ko fine-tune karo.

17.3 Denoising Autoencoders

Denoising autoencoders ko noisy input se clean output banana sikhaya jata hai — input me noise dalo, model ko original image reconstruct karni hoti hai. Isse model robust features seekhta hai.

Book Fashion MNIST par denoising autoencoder banata hai — noisy images se clean images wapas milti hain.

17.4 Sparse Autoencoders

Sparse autoencoders me latent code ko sparse banaya jata hai — matlab har input ke liye sirf kuch hi units active hote hain. Isse model meaningful features seekhta hai, jaise edges aur shapes.

Sparsity ko KL divergence penalty se ya L1 regularisation se enforce kiya jata hai.

17.5 Variational Autoencoders (VAEs)

Variational autoencoders probabilistic hote hain — encoder ek distribution (mean aur variance) output karta hai, decoder usse sample karke naya data banata hai. Book latent dim 2 wala VAE banata hai Fashion MNIST par.

VAE ka loss do parts ka hota hai: reconstruction loss (output input jaisa ho) aur KL divergence (latent distribution normal jaisi ho). Isse latent space smooth banta hai — beech ke points se naye samples ban sakte hain.

17.6 Other Autoencoders — Contractive, Stacked, etc.

Book aur autoencoder variants ko cover karta hai: contractive autoencoders (input me chhote changes se output na badle), stacked autoencoders (kai layers), aur generative autoencoders.

Har variant ka apna use hai — lekin basic idea wahi hai: chhoti representation se meaningful information nikalo.

17.7 Generative Adversarial Networks (GANs)

GANs me do networks ek dusre se compete karte hain: generator fake data banata hai, discriminator asli aur fake me farak karta hai. Dono ek saath train hote hain — generator behtar fake banata hai, discriminator behtar pakadta hai.

17.8 Deep Convolutional GANs (DCGANs)

Book DCGAN banata hai Fashion MNIST par — generator aur discriminator dono convolutional hote hain. Training ke dauran generated images lagbhag 50 epochs me behtar hote jate hain — shuru me noise, phir pehchanne layak kapde.

DCGAN ke rules: pooling ki jagah strided convolutions, batch norm dono networks me, ReLU/Leaky ReLU activations, aur tanh output layer me.

17.9 GAN Training Challenges — Mode Collapse aur Stability

GANs train karna mushkil hai:

  • Mode collapse — generator sirf kuch hi tarah ke outputs banata hai, diversity khatm ho jati hai.
  • Training instability — generator aur discriminator ka balance bigad jata hai.
  • Vanishing gradients — discriminator bahut strong ho jaye to generator ko signal nahi milta.

Fixes: Wasserstein GAN, gradient penalty, label smoothing, feature matching — book inhe briefly cover karta hai.

17.10 Summary aur Exercises

Generative models ka safar: autoencoders (compression) → VAEs (sampling) → GANs (realistic generation). Har model ka apna use hai — aur aaj ke generative AI ki neev yahin hai.

Interview FAQs


Hands-On ML par interview me sabse zyada poochhe jaane wale 36 sawaal — har jawaab is book ke content par based hai.




01Machine Learning kya hai, aur traditional programming se kaise alag hai?
Machine Learning computer science ka wo field hai jo computers ko bina explicitly program kiye data se seekhne ki ability deta hai. Traditional programming me programmer rules likhta hai aur data daal kar answers nikalta hai; ML me data aur answers daal kar rules nikale jate hain. Spam filter iska classic example hai — rules likhne ke bajaye filter ko spam aur non-spam ke examples dikhao, wo khud pattern seekh lega. ML wahan jeet-ta hai jahan rules likhna mushkil ho, rules badalte rehte hon, data bahut bada ho, ya system ko naye data se adapt karna ho.


02Supervised, unsupervised, semisupervised aur reinforcement learning me farak kya hai?
Farak training data aur feedback me hai. Supervised learning labelled data istemal karta hai — classification aur regression iske kaam hain. Unsupervised learning unlabelled data par kaam karta hai — clustering, dimensionality reduction aur anomaly detection. Semisupervised me thoda labelled aur bahut saara unlabelled data hota hai. Reinforcement learning me environment se reward signal milta hai — agent reward maximise karna seekhta hai, jaise game khelna. Interview me ek line me jawaab do: labels hain ya nahi, aur feedback kaisa hai.


03Instance-based aur model-based learning me kya farak hai?
Instance-based learning training examples ko yaad rakhta hai aur naye example ki prediction similarity se karta hai — k-nearest neighbours iska example hai. Model-based learning data se ek model banata hai, jaise ek line ya equation, aur prediction us model se karta hai — training ke baad data ki zaroorat nahi padti. Model-based algorithms parameter values dhoondhte hain jo ek cost function ko minimise karte hain. Instance-based ko training me kuch nahi karna padta lekin prediction slow hoti hai; model-based ko training me mehnat karni padti hai lekin prediction tez hoti hai.


04Overfitting aur underfitting kya hain, aur inhe kaise pehchanein aur theek karein?
Overfitting matlab model training data ko rat leta hai aur naye data par fail hota hai — training error kam, validation error zyada, dono ke beech gap. Underfitting matlab model bahut simple hai aur pattern hi nahi pakad pata — dono errors upar hain aur kareeb hain. Learning curves se pehchano: dono curves upar plateau karein to underfitting, gap ho to overfitting. Overfitting ke solutions: zyada data, regularisation (Ridge/Lasso/dropout), early stopping, ya simple model. Underfitting ke solutions: zyada complex model, zyada features, ya kam regularisation.


05Test set, validation set aur cross-validation ka kya kaam hai?
Test set wo data hai jo model ne kabhi dekha hi nahi — usi se asli performance naapi jati hai, aur use sirf end me ek baar chhoo. Validation set hyperparameters tune karne ke liye hota hai — model selection ke liye. Cross-validation data ko kai hisson me baant kar har baar ek hissa test ke liye istemal karta hai aur average leta hai — isse generalisation ka andaza zyada reliable hota hai. Data snooping se bacho — test set ko baar-baar dekh kar usi ke hisaab se model badalna matlab test set bhi training set ban jana.


06California housing project me stratified sampling kyun istemal ki gayi thi?
Stratified sampling se test set me income distribution full data jaisi hi rehti hai. Data ko income category ke hisaab se baanta gaya (bins 1.5, 3.0, 4.5, 6.0 — 5 categories) aur har category se proportionally sample liya gaya, StratifiedShuffleSplit test_size 0.2 aur random_state 42 ke saath. Random split se aisa guarantee nahi milta — test set biased ho sakta tha, aur performance ka andaza galat ho jata. California housing me 20,640 rows aur 10 attributes hain, aur income median house value se sabse zyada correlate karta hai (lagbhag 0.69).


07Feature scaling kab zaroori hai aur kab nahi?
Scaling gradient-descent aur distance-based models ke liye zaroori hai — jaise linear regression with GD, SVM, k-NN aur neural networks — kyunki bade scale wale features dominate karne lagte hain. Tree-based models (decision tree, random forest, gradient boosting) ko scaling se farak nahi padta kyunki wo thresholds par split karte hain. MinMaxScaler values ko 0–1 me lata hai, StandardScaler mean 0 aur std 1 karta hai. SVM se pehle scaling zaroor lagao — scaling ke bina SVM kharab kaam karta hai.


08Pipeline aur ColumnTransformer kyun istemal karte hain?
Pipeline preprocessing aur model ko ek unit me bandhta hai — isse data leakage rukta hai aur code clean rehta hai. ColumnTransformer alag columns par alag transformations lagata hai — jaise numeric par impute + scale, categorical par one-hot encode. California housing me ColumnTransformer se numeric features par median imputation, standardisation aur engineered features (rooms_per_household, bedrooms_per_room, population_per_household) lage, aur ocean_proximity par one-hot encoding lagi. Pipeline ke bina cross-validation me preprocessing galat ho jata hai — jaise poore data par scaler fit karna, jo leakage hai. Pipeline se har fold me preprocessing sirf training data par fit hoti hai.


09Accuracy kab misleading hoti hai? Precision, recall aur F1 kya hain?
Accuracy imbalanced data par misleading hoti hai. MNIST 5-detector ke example me dummy classifier (hamesha 'not-5') ki accuracy 90% ke aas-paas hoti hai bina kuch seekhe. Precision = TP/(TP+FP) — predicted positive me se kitne sahi the. Recall = TP/(TP+FN) — actual positive me se kitne pakde gaye. F1 = 2·P·R/(P+R) — dono ka harmonic mean. 2nd edition ke MNIST 5-detector matrix (TP 3,912, FP 687, FN 1,018, TN 5,383) se precision lagbhag 0.85, recall lagbhag 0.79, F1 lagbhag 0.82 milte hain. Threshold badhao to precision badhta hai, recall girta hai — is trade-off ko precision-recall curve se dekho.


10Linear regression ko Normal Equation se kaise solve karte hain, aur gradient descent se kya farak hai?
Normal Equation θ̂ = (XᵀX)⁻¹Xᵀy se seedha solution nikalta hai — y=4+3x+noise wale data par θ̂ lagbhag [4.22, 2.98] milta hai. Ye small-medium data par fast hai lekin bade data par slow ho jata hai kyunki matrix inversion O(n³) hoti hai. Gradient descent iterative hai — learning rate se step-by-step minimum ki taraf badhta hai; batch GD η=0.1, 1,000 epochs se wahi θ milta hai. SGD har example par update karta hai — fast lekin noisy. Mini-batch GD beech ka rasta hai. Bade data par GD, chhote data par Normal Equation behtar hai.


11Polynomial regression se overfitting kaise hota hai, aur regularisation kaise madad karta hai?
Polynomial degree badhane se model training data ko ratne lagta hai — degree 300 par training error lagbhag 0 ho jata hai lekin validation error badh jata hai. Regularisation weights ko bada hone se rokta hai: Ridge (L2) weights ko chhota karta hai, Lasso (L1) kuch weights ko exactly zero kar deta hai — sparse model aur automatic feature selection. Degree-2 fit par Ridge α=0.1 se θ̂ lagbhag [−0.37, 0.42, 0.55] aur Lasso α=0.1 se θ̂ lagbhag [−0.07, 0.36, 0.41] milte hain; Lasso α=10 par θ̂ lagbhag [0.13, 0.0, 0.0] — weights zero ho gaye. Elastic Net dono ka mix hai.


12Logistic regression aur softmax regression me kya farak hai?
Logistic regression binary classification ke liye hai — sigmoid se probability nikalta hai, decision boundary linear hoti hai. Softmax regression (multinomial logistic regression) multi-class ke liye hai — softmax se har class ki probability nikalta hai, aur sabse zyada probability wali class predict karta hai. Iris dataset par logistic regression lagbhag 95% accuracy deti hai, aur softmax regression lagbhag 96–98%. Dono me cross-entropy loss istemal hoti hai. Softmax essentially kai logistic regressions ko ek saath train karne jaisa hai.


13SVM kya hai? Margin aur support vectors ka kya matlab hai?
SVM (Support Vector Machine) wo decision boundary dhoondhta hai jo classes ke beech sabse bada margin banaye — margin jitna bada, generalisation utna behtar. Support vectors woh examples hote hain jo margin ke bilkul paas hote hain — inhi se decision boundary banti hai, baaki examples se farak nahi padta. Hard margin SVM sirf linearly separable data par kaam karta hai; soft margin SVM kuch misclassifications allow karta hai (C se control hota hai). Kernel trick se SVM nonlinear boundaries bhi bana sakta hai — RBF kernel sabse zyada istemal hota hai.


14Decision tree kaise kaam karta hai? Gini impurity aur entropy me kya farak hai?
Decision tree data ko sawal-jawab se split karta hai — har node par ek feature aur threshold chun kar data ko do hisson me baanta hai, jab tak leaves pure na ho jayein. Split chunne ke liye impurity measure karte hain: Gini impurity = 1 − Σ(pᵢ²), entropy = −Σ(pᵢ·log₂pᵢ). Dono hi similar kaam karte hain — Gini thoda fast hai, entropy thoda zyada information-theoretic hai. Practical farak chhota hota hai. Tree ko bina rok ke badhaya to overfit ho jata hai — isliye max_depth, min_samples_split aur min_samples_leaf se rokna padta hai.


15Random Forest kya hai, aur ye single tree se behtar kyun hai?
Random Forest kai decision trees ka ensemble hai — har tree random subset of data (bagging) aur random subset of features par train hota hai, phir sabki vote se prediction hoti hai. Isse variance kam hoti hai — single tree overfit karta hai, lekin kai trees ka average stable hota hai. California housing par Random Forest ka 10-fold CV RMSE lagbhag 50,500 tha, jabki single tree ka lagbhag 71,000 aur linear regression ka 68,000–71,000. Feature importances se pata chalta hai ki median_income sabse important hai (lagbhag 0.335), phir income_cat (lagbhag 0.163).


16Bagging, boosting aur stacking me kya farak hai?
Bagging (Bootstrap Aggregating) me kai models ko data ke random subsets par train karke unka average/vote lete hain — Random Forest iska example hai, variance kam hoti hai. Boosting me models ek ke baad ek train hote hain — har naya model pichhle model ki galtiyon par focus karta hai — AdaBoost aur Gradient Boosting iske examples hain, bias kam hota hai. Stacking me kai alag models ki predictions ko ek meta-model (blender) ko input dekar final prediction banayi jati hai. Book me Gradient Boosting California housing par sabse behtar tha (test RMSE lagbhag 47,900).


17PCA kya hai, aur dimensionality reduction kab karte hain?
PCA (Principal Component Analysis) data ko kam dimensions me project karta hai — wo directions dhoondhta hai jinme variance sabse zyada hoti hai (principal components). MNIST par pehle 2 components 91% variance rakhte hain (0.758 + 0.152), aur 154 components par 95% variance milti hai. 154/784 matlab 20% se kam size — 5× compression. PCA se training fast hoti hai, visualisation aasan hoti hai, aur noise kam hota hai. Lekin PCA linear hai — nonlinear patterns ke liye kernel PCA ya autoencoders chahiye hote hain.


18K-Means clustering kaise kaam karta hai? K kaise chunein?
K-Means data ko K clusters me baanta hai — pehle K centroids randomly chuno, phir har point ko nearest centroid se jodo, phir centroids ko update karo, aur repeat karo jab tak centroids na ruk jayein. K chunne ke tareeke: elbow method (inertia vs K ka graph — jahan elbow bane), silhouette score (kitna achha cluster bana — 1 ke kareeb behtar), ya domain knowledge. Book me K-Means blobs aur moons datasets par dikhaya gaya hai. K-Means spherical clusters par achha kaam karta hai, lekin elongated ya alag shapes par fail ho sakta hai — tab DBSCAN ya Gaussian mixtures try karo.


19Perceptron aur MLP me kya farak hai? XOR problem kya thi?
Perceptron single-layer neural network hai — sirf linearly separable problems solve kar sakta hai. Early researchers ne dikhaya tha ki single-layer perceptron XOR jaisi simple problem bhi nahi solve kar sakta — ye AI winter ki ek wajah bani. MLP (Multi-Layer Perceptron) me ek ya zyada hidden layers hote hain — hidden layers se nonlinear boundaries ban sakti hain, isliye MLP XOR solve kar sakta hai. Principle me MLP kisi bhi continuous function ko approximate kar sakta hai (universal approximation theorem).


20Activation functions me ReLU, sigmoid aur tanh me kya farak hai?
Sigmoid 0–1 ke beech output deta hai lekin saturate ho jata hai — bade inputs par gradient lagbhag 0 ho jata hai (vanishing gradient). Tanh −1 se +1 deta hai, zero-centred hai — sigmoid se thoda behtar. ReLU (max(0, z)) hidden layers ka default hai — fast hai, positive inputs par saturate nahi hoti, lekin 'die' kar sakti hai (hamesha 0 output). Leaky ReLU, ELU aur SELU ReLU ke variants hain jo dying ReLU se bachate hain. Output layer me classification ke liye softmax, regression ke liye linear activation istemal hoti hai.


21Backpropagation kya hai, aur ye kaise kaam karta hai?
Backpropagation training ka algorithm hai: pehle forward pass me input se output tak compute karo aur loss nikalo, phir backward pass me chain rule se har weight ke liye gradient nikalo, aur gradient descent se weights update karo. Reverse-mode autodiff se ye efficient hota hai — ek backward pass me saare gradients mil jate hain. Book ek chhote two-layer example se samjhata hai — forward me values compute karo, backward me gradients. Yehi backprop hai — deep learning ki engine.


22Vanishing gradients problem kya hai, aur iske solutions kya hain?
Deep networks me gradients layers se guzarte hue shrink ho jate hain (vanish) ya explode ho jate hain — neeche wali layers train hi nahi hoti. Wajah: sigmoid/tanh saturate hote hain, aur kai layers se gradient multiply hota hai. Solutions: ReLU jaise non-saturating activations, behtar initialisation (fan-average aur ReLU-friendly), batch normalisation, gradient clipping, aur skip connections (ResNet). Book ka Fashion MNIST model batch normalisation ke saath lagbhag 89–90% accuracy pata hai aur faster converge hota hai.


23Batch Normalisation kya hai, aur ye kyun madad karta hai?
Batch Normalisation har layer ke inputs ko normalise karta hai — zero mean, unit variance per mini-batch — phir learnable γ (scale) aur β (shift) se adjust karta hai. Isse training fast hoti hai, higher learning rate istemal kar sakte ho, aur overfitting kam hota hai (regulariser ki tarah kaam karta hai). Book ise activation se pehle lagata hai. Fashion MNIST par BN wala model lagbhag 89–90% accuracy pata hai. Test time par BN training ke running averages istemal karta hai, batch statistics nahi.


24Optimizers me SGD, Momentum, Adam me kya farak hai?
SGD (stochastic gradient descent) har batch par gradient se update karta hai — simple lekin slow ho sakta hai. Momentum velocity accumulate karta hai — plateaus aur ravines ko paar karne me madad karta hai. Look-ahead momentum (NAG) aage dekh kar gradient compute karta hai — momentum se behtar. Adam momentum + RMSProp ka combination hai, bias correction ke saath — book ki default recommendation hai (lr=0.001). Book Fashion MNIST par optimisers ko compare karta hai — Adam sabse fast converge karta hai. Adamax aur Nadam Adam ke variants hain.


25Dropout kya hai, aur ye overfitting kaise rokta hai?
Dropout training ke dauran randomly units ko drop kar deta hai (rate 0.2–0.5) — har step par alag sub-network train hota hai, isliye model kisi ek unit par depend nahi karta. Test time par saare units istemal hote hain, output ko keep probability se scale karke (inverted dropout). Book ka Fashion MNIST model dropout 0.2 ke saath lagbhag 88–89% accuracy pata hai aur kam overfit karta hai. Dropout ek tarah ka ensemble hai — kai sub-networks ka average. L1/L2 regularisation, early stopping aur data augmentation bhi overfitting rokte hain.


26Transfer learning kya hai, aur ye kab istemal karte hain?
Transfer learning me kisi similar task par train hue model ki lower layers reuse karte ho — unhe freeze karo, sirf top layers train karo, phir optionally unfreeze karke low learning rate se fine-tune karo. Fayda: kam data par bhi achha model — kyunki lower layers ne pehle se hi general features seekh liye hote hain (edges, shapes, patterns). Book flowers dataset par Xception transfer learning karta hai — 92–95% accuracy milti hai, jabki scratch se sirf lagbhag 70%. ImageNet par train hue models (ResNet, Xception, EfficientNet) se shuru karna standard practice hai.


27CNN me convolution aur pooling layers kya karte hain?
Convolutional layer filters (kernels) ko image par slide karke feature maps banata hai — har filter ek feature dhoondhta hai (edge, texture). Parameter sharing se parameters bahut kam hote hain Dense layer se. Pooling layer feature maps ko chhota karta hai — max pooling har window ka sabse bada value leta hai, average pooling average leta hai. Pooling se translation invariance milti hai aur computation kam hota hai. CNN ka fayda: images me local patterns aur hierarchy pakad sakta hai — pehle edges, phir shapes, phir objects.


28ResNet me skip connections kyun zaroori hain?
Skip connections (residual connections) input ko seedha output me jod dete hain — output = F(x) + x. Isse bahut gehri networks train karna possible hota hai kyunki gradients skip connection se seedha peeche ja sakte hain — vanishing gradient problem kam hota hai. ResNet-34 CIFAR-10 par 10 epochs ke baad lagbhag 90% accuracy deta hai, aur poori training ke baad lagbhag 90–92%. ImageNet par ResNet ka top-5 error 3.57% tha, jabki AlexNet ka 15.3% — architectures behtar hote gaye.


29RNN, LSTM aur GRU me kya farak hai?
RNN (recurrent neural network) me output wapas input me jata hai — isse network ko 'memory' milti hai, sequence data ke liye achha hai. Lekin RNN lambi dependencies seekhne me mushkil hoti hai — vanishing gradients ki wajah se. LSTM cell me teen gates hote hain (forget, input, output) aur ek cell state jo lambi memory rakhta hai — gates decide karte hain ki kya yaad rakho, kya bhool jao. GRU LSTM ka simpler version hai — sirf do gates (reset aur update), cell state nahi. Dono hi vanishing gradient problem ko solve karte hain. Time series forecasting me 1-step RMSE lagbhag 0.06 milti hai, lekin 10-step me badh kar lagbhag 0.3–0.5 ho jati hai.


30Attention mechanism kya hai, aur Transformer kyun important hai?
Attention ka idea: decoder har output step par input ke sabhi parts ko dekhta hai aur decide karta hai ki kis part par dhyaan de — additive attention ek chhota network se scores compute karta hai, dot-product attention query-key dot product se. NMT par attention se BLEU score lagbhag 13.7 se badh kar lagbhag 18.8 ho gaya. Transformer (2017 ke ek paper se) RNN ko poori tarah hata deta hai — sirf self-attention istemal karta hai. Isse parallel training hoti hai aur lambi dependencies behtar pakdi jati hain. Transformer ke parts: multi-head attention, positional encoding, feed-forward layers, layer normalisation. Yehi architecture aaj ke bade language models ki neev hai.


31Autoencoders, VAEs aur GANs me kya farak hai?
Autoencoder input ko chhoti latent representation me compress karke wapas reconstruct karta hai — Fashion MNIST par 784 → 100 → 30 → 100 → 784 architecture istemal hota hai. VAE (variational autoencoder) probabilistic hota hai — encoder ek distribution (mean aur variance) output karta hai, decoder usse sample karke naya data banata hai; loss me reconstruction + KL divergence hote hain. GAN me do networks compete karte hain — generator fake data banata hai, discriminator asli aur fake me farak karta hai; dono ek saath behtar hote hain. DCGAN Fashion MNIST par lagbhag 50 epochs me pehchanne layak images banane lagta hai. GANs ki problems: mode collapse aur training instability.


32Reinforcement learning kya hai? Q-learning aur policy gradients me kya farak hai?
Reinforcement learning me agent environment me actions leta hai, rewards pata hai, aur policy seekhta hai — kaunsi state me kaunsa action best hai. Policy gradients (jaise REINFORCE) policy ko seedha optimise karte hain — policy network actions ke probabilities deta hai. Q-learning har state-action pair ki Q-value seekhta hai — kitna future reward milega; DQN me Q-values ko neural network se approximate karte hain, experience replay aur target network se stable training hoti hai. CartPole-v1 me policy 200 steps tak pole balance rakhna seekhti hai aur ek achhe run me lagbhag 70 episodes me solve ho jata hai. Credit assignment problem: end me mile reward ka credit kis action ko do — discounted rewards se solve hota hai.


33TensorFlow me custom training loop kab likhte hain, aur GradientTape kya hai?
Custom training loop tab likhte hain jab model.fit() se kaam na chale — jaise GANs, ya aisi training jisme do models ek saath train hote hon. GradientTape TensorFlow ka autodiff engine hai: with tf.GradientTape() as tape ke andar jo operations Variables par hote hain, wo record hote hain, phir tape.gradient(loss, variables) se gradients milte hain. Manual loop me epochs, batches, loss, gradients aur optimizer.apply_gradients likhna padta hai — aur dropout/BN ke liye training flag handle karna padta hai. Book Fashion MNIST MLP ko manual loop se train karke lagbhag 87–88% accuracy pata hai, model.fit() jaisi hi.


34tf.data pipeline kyun zaroori hai, aur TFRecord kya hai?
tf.data se efficient input pipelines banti hain — map, filter, shuffle, batch, prefetch (AUTOTUNE) aur cache se preprocessing aur training overlap hote hain, GPU kabhi idle nahi rehta. TFRecord ek binary, efficient storage format hai — Example/Feature structure ke saath; book housing data ko 5 files me sharded TFRecord me likhta hai aur TFRecordDataset se padhta hai. Preprocessing layers (Normalization, StringLookup, CategoryEncoding, TextVectorization) se features ko model-ready banao. TF Transform se training aur serving me wahi transform lagta hai — train/serve skew khatm ho jata hai.


35Model ko production me kaise deploy karte hain? TF Serving, TFLite aur TF.js me kya farak hai?
TensorFlow Serving se model ko production server par REST/gRPC API se serve karte ho — SavedModel format me export karke. TensorFlow Lite se model ko mobile aur embedded devices par chalate ho — quantisation se model lagbhag 1 MB se lagbhag 250 KB ho jata hai, accuracy drop 1% se kam hoti hai, aur phone par offline chalta hai. TensorFlow.js se model web browser me chalta hai — user ke browser me inference hota hai. GPUs se CNN training 10–50× faster hoti hai. Distributed training me MirroredStrategy se 2 GPUs par near-linear speedup milta hai.


362nd edition, 3rd edition aur 4th edition me kya farak hai?
2nd edition (2019) TensorFlow 2 aur Keras par based hai — 848 pages, 19 chapters aur 7 appendices. 3rd edition (2022) wahi structure rakhta hai lekin TensorFlow 2 ke naye versions, naye chapters aur updated examples ke saath aata hai. 4th edition (2025) PyTorch par shift ho gaya hai — Scikit-Learn ke saath PyTorch istemal karta hai, TensorFlow ki jagah. 2nd edition seekhne ke liye abhi bhi relevant hai kyunki core ML concepts — regression, classification, SVM, trees, ensembles, PCA, clustering aur deep learning ki neev — sabhi editions me wahi hain. Code ke liye homl.info/2 istemal karo.
